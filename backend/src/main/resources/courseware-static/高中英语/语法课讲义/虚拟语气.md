# 虚拟语气

## 一、语气的本质

语气（Mood）是谓语动词的一种形式，表达说话人对动作或状态的**态度**——动作是事实、假设、愿望、命令还是建议。

英语有三种语气：

· **陈述语气**：陈述事实或提出疑问。谓语动词按正常时态、主谓一致变化。

· **祈使语气**：发出命令、请求、建议。省略主语 you，动词用原形。

· **虚拟语气**：表达与事实相反、难以实现、主观愿望、建议要求等**非事实**情况。动词采用特殊形式，**不再遵循正常的时态呼应和主谓一致**。

判断一个句子是否需要虚拟语气，核心不是"有没有 if"，而是**说话人是否在陈述事实**。

## 二、条件句中的虚拟语气

条件句分为真实条件句和虚拟条件句。真实条件句用陈述语气；虚拟条件句表示假设、与事实相反，用虚拟语气。

### 与现在事实相反

从句：If + 主语 + **过去式**（be 动词统一用 were，不管人称）

主句：主语 + **would/could/should/might + 动词原形**

例：

· If I **were** you, I **would not miss** the chance.（我不可能是你）

· If he **knew** her phone number, he **would call** her.（他不知道）

注意：be 动词在第一、三人称单数口语中偶见 was，但正式写作和考试中统一用 **were**。

### 与过去事实相反

从句：If + 主语 + **had + 过去分词**

主句：主语 + **would/could/should/might + have + 过去分词**

例：

· If I **had got** there earlier, I **should have met** her.（我没早点到）

· If she **had studied** harder, she **would have passed** the exam.（她没努力，没通过）

### 与将来事实相反（可能性极小）

从句有三种形式，语气一次比一次弱：

· If + 主语 + **过去式**（可能性较小）

· If + 主语 + **were to + 动词原形**（可能性极小，近乎不可能）

· If + 主语 + **should + 动词原形**（万一）

主句：主语 + **would/could/should/might + 动词原形**

例：

· If it **rained** tomorrow, the sports meeting **would be** put off.

· If the sun **were to rise** in the west, I **would change** my mind.（太阳绝不会从西边升起）

· If he **should fail**, he **would try** again.（万一失败）

### 混合虚拟语气

主句和从句的时间不一致时，动词形式**按各自的时间**调整，不需要保持一致。

例：

· If I **had worked** hard at school, I **would be** an engineer now.
  （从句与过去事实相反 had worked；主句与现在事实相反 would be）

· If he **had followed** my advice then, he **would not be** in trouble now.

做题时先分别判断主句和从句各自指的是什么时间，再套用对应的公式，不要被表面的"对称"迷惑。

### 省略 if 的倒装

虚拟条件句中含有 were、had、should 时，可以省略 if，把 were/had/should 提至主语前，构成部分倒装。

例：

· **Were I** you, I would not miss the chance. (= If I were you)

· **Had I** known earlier, I would have helped. (= If I had known)

· **Should he** come, tell him to wait. (= If he should come)

注意：否定式倒装时，not 放在主语后，不与助动词缩写。

## 三、介词或介词短语隐含的虚拟

without、but for、otherwise、or 等词可以隐含虚拟条件，主句仍用虚拟语气的谓语形式。

· Without electricity, life **would be** quite different today.（= If there were no electricity）

· But for your help, I **would have failed**.（= If you hadn't helped me）

· I was busy that day; otherwise I **would have come**.（= If I had not been busy）

## 四、名词性从句中的虚拟语气

表示"建议、要求、命令、坚持"等意义的动词，其后的宾语从句用虚拟语气：**(should) + 动词原形**，should 可以省略。

### 一坚持二命令三建议四要求

· 一坚持：**insist**

· 二命令：**order, command**

· 三建议：**advise, suggest, propose, recommend**

· 四要求：**demand, require, request, ask**

例：

· The teacher suggested that every student **(should) wear** school uniform.

· He demanded that the report **(should) be** finished by Friday.

### 特殊情况：insist 和 suggest 的词义辨析

这两个词不表示"坚持/建议"时，后面的宾语从句**用陈述语气**，不用虚拟。

· She insisted that she **was** innocent.（insist = 坚称，事实陈述 → was）

· The expression on his face suggested that he **was** angry.（suggest = 表明、暗示 → was）

判断方法：把 insist 译为"坚持要求"还是"坚称"，把 suggest 译为"建议"还是"表明"。前者用虚拟，后者用陈述。

### 派生形式

上述动词的名词形式（suggestion, order, demand, request 等）和过去分词作表语时，相关从句同样用 (should) + 动词原形：

· My suggestion is that we **(should) start** early.

· It is required that the students **(should) wear** uniforms.

· It is important / necessary / essential / strange that he **(should) be** present.

## 五、其他固定虚拟结构

### wish 后的宾语从句

wish 表示不可能或难以实现的愿望，从句谓语按时间倒退一格：

· 与现在事实相反：过去式（be → were）
  I wish I **were** as tall as you.

· 与过去事实相反：had + 过去分词
  I wish I **had not made** that mistake.

· 与将来愿望：would/could + 动词原形
  I wish it **would rain** tomorrow.

### if only

if only = "要是……就好了"，用法与 wish 相同，语气更强。

· If only I **had taken** your advice!

### would rather

would rather 后接从句时，用虚拟语气：

· 对现在或将来的虚拟：过去式
  I would rather you **came** tomorrow.

· 对过去的虚拟：had + 过去分词
  I would rather you **had not told** her the news.

### It is (high/about) time that...

"是该做某事的时候了"，从句用过去式（也可用 should + 动词原形，但 should 不可省）：

· It is high time that we **took** measures to protect the environment.

### as if / as though

"仿佛、好像"，从句表示不真实的情况时用虚拟语气：

· 与现在事实相反：过去式
  He talks as if he **knew** everything.

· 与过去事实相反：had + 过去分词
  She looked as if she **had seen** a ghost.

注意：如果 as if 后的情况可能是事实，仍用陈述语气。

### for fear that / in case

"以防、以免"，从句用 should + 动词原形，should 可省略：

· He took his umbrella in case it **(should) rain**.

## 六、判断虚拟语气的核心步骤

拿到一个空格，按以下顺序判断：

1. **是不是事实？** 如果是事实陈述，用陈述语气的正常时态；如果是假设、愿望、建议、命令，进入下一步。

2. **时间是什么？** 从句和主句分别指现在、过去还是将来？混合时间要分别判断。

3. **是什么结构？** 是 if 条件句、suggest/demand 类宾语从句、wish/would rather/it's time 等固定结构，还是 without/but for 隐含条件？

4. **套用公式。** 条件句按"现在/过去/将来"三套公式；名词性从句统一 (should) + 动词原形；固定结构按各自规则。

最容易错的不是背不出公式，而是**把事实当成假设**或**把假设当成事实**。记住：虚拟语气的本质是"说话人知道这不是真的"。
