# 从键和官能团的角度看有机合成

## 有机合成的核心逻辑

**官能团**是有机化学的核心——它决定了有机物的化学性质。而**共价键的断裂与形成**则是所有有机反应的底层逻辑。从这两个角度出发，有机合成可以理解为：

**目标**：通过断键与成键，将原料中的官能团转化为目标产物中的官能团。

**方法**：选择适当的试剂和条件，让特定位置的共价键以特定方式断裂，并形成新的共价键。

有机合成的本质是官能团的转化，而官能团转化的本质是σ键和π键的选择性断裂与形成。

## 共价键的断裂方式与反应类型

有机反应中，共价键的断裂方式决定了反应的分类和产物：

### 取代反应——"断σ成σ"

- 一个σ键断裂，另一个σ键形成
- 如烷烃的卤代：$\mathrm{C-H}$ 断裂，$\mathrm{C-X}$ 形成
- 如酯化反应：醇的 $\mathrm{O-H}$ 断裂，酸的 $\mathrm{C-O}$ 断裂

### 加成反应——"断π成σ"

- π键断裂，形成两个新的σ键
- 如烯烃加氢：$\mathrm{C=C}$ 的π键断裂，形成两个 $\mathrm{C-H}$
- 如羰基加成：$\mathrm{C=O}$ 的π键断裂，形成 $\mathrm{C-O}$ 和 $\mathrm{C-H}$

### 消去反应——"断σ成π"

- 两个σ键断裂，形成一个π键
- 如醇消去：$\mathrm{C-O}$ 和 $\mathrm{C-H}$ 断裂，形成 $\mathrm{C=C}$
- 如卤代烃消去：$\mathrm{C-X}$ 和 $\mathrm{C-H}$ 断裂，形成 $\mathrm{C=C}$

### 氧化还原反应——官能团中 O 和 H 的变化

- 氧化：得氧或失氢（如醇→醛→酸）
- 还原：得氢或失氧（如醛→醇）

# 常见官能团与特定试剂的反应

## 与金属钠反应（—OH 和 —COOH）

**反应的本质**：含有活泼氢的官能团（—OH、—COOH）能与 Na 发生置换反应，生成 $\mathrm{H_2}$。

| 官能团 | 反应物 | 产物 | 反应类型 |
| :--- | :--- | :--- | :--- |
| 醇羟基（$\mathrm{R-OH}$） | $\mathrm{Na}$ | $\mathrm{R-ONa + \frac{1}{2}H_2}$ | 置换反应 |
| 酚羟基（$\mathrm{Ar-OH}$） | $\mathrm{Na}$ | $\mathrm{Ar-ONa + \frac{1}{2}H_2}$ | 置换反应 |
| 羧基（$\mathrm{-COOH}$） | $\mathrm{Na}$ | $\mathrm{R-COONa + \frac{1}{2}H_2}$ | 置换反应 |

**定量关系**：$2\mathrm{mol\ -OH} \sim 1\mathrm{mol\ H_2}$，$2\mathrm{mol\ -COOH} \sim 1\mathrm{mol\ H_2}$。

**注**：若一个有机物分子含多个—OH 或—COOH，则按个数比例计算 $\mathrm{H_2}$ 的量。

## 与氢氧化钠反应

能与 $\mathrm{NaOH}$ 反应的官能团及其反应类型：

| 官能团/结构 | 反应类型 | 说明 |
| :--- | :--- | :--- |
| 羧基（—COOH） | 中和反应 | 生成羧酸钠和水 |
| 酚羟基（$\mathrm{Ar-OH}$） | 中和反应 | 生成酚钠和水（弱酸性） |
| 酯基（—COOR） | 水解反应 | 酸性条件下可逆，碱性条件下完全 |
| 卤代烃（$\mathrm{R-X}$） | 水解/消去 | $\mathrm{NaOH}$ 水溶液水解，$\mathrm{NaOH}$ 醇溶液消去 |

**注**：醇羟基不与 $\mathrm{NaOH}$ 反应。

## 银镜反应与醛基检验

**反应对象**：醛基（—CHO）

**试剂**：银氨溶液 $[\mathrm{Ag(NH_3)_2}]OH$（水浴加热）

**原理**：
$$\mathrm{R-CHO + 2[Ag(NH_3)_2]OH \xrightarrow{水浴} R-COONH_4 + 2Ag \downarrow + 3NH_3 + H_2O}$$

**定量关系**：
- 一元醛：$1\mathrm{mol\ -CHO} \sim 2\mathrm{mol\ Ag}$
- 甲醛：$1\mathrm{mol\ HCHO} \sim 4\mathrm{mol\ Ag}$（相当于有两个醛基）
- 二元醛：$1\mathrm{mol\ 二元醛} \sim 4\mathrm{mol\ Ag}$

**能发生银镜反应的物质**：醛、甲酸（$\mathrm{HCOOH}$）、甲酸酯（$\mathrm{HCOOR}$）、甲酸盐、葡萄糖、麦芽糖等（都含有醛基或能转化为醛基）。

## 与新制 $\mathrm{Cu(OH)_2}$ 反应

**反应对象**：醛基（—CHO）

**试剂**：新制 $\mathrm{Cu(OH)_2}$（碱性条件，加热）

**原理**：
$$\mathrm{R-CHO + 2Cu(OH)_2 + NaOH \xrightarrow{\triangle} R-COONa + Cu_2O \downarrow + 3H_2O}$$

**现象**：产生砖红色 $\mathrm{Cu_2O}$ 沉淀。

**定量关系**：$1\mathrm{mol\ -CHO} \sim 2\mathrm{mol\ Cu(OH)_2} \sim 1\mathrm{mol\ Cu_2O}$

**与 $\mathrm{NaHCO_3}$ 反应**：只有羧基（—COOH）能与 $\mathrm{NaHCO_3}$ 反应产生 $\mathrm{CO_2}$，醇羟基、酚羟基均不反应。

## 与溴水的反应总结

| 官能团/结构 | 反应类型 | 说明 |
| :--- | :--- | :--- |
| 碳碳双键（$\mathrm{C=C}$） | 加成反应 | 褪色 |
| 碳碳三键（$\mathrm{C\equiv C}$） | 加成反应 | 褪色 |
| 酚羟基的邻、对位 H | 取代反应 | 苯酚与浓溴水产生白色沉淀 |
| 醛基（—CHO） | 氧化反应 | 褪色 |
| 苯及苯的同系物 | 不反应 | 仅萃取 |

# 醇→醛→酸的连续氧化

## 氧化过程的官能团变化

这是有机合成中最基础、最重要的氧化路线：

$$\mathrm{R-CH_2OH \xrightarrow{Cu/O_2,\ \triangle} R-CHO \xrightarrow{氧化剂} R-COOH}$$

**第一步：醇 → 醛**

- 条件：$\mathrm{Cu}$ 或 $\mathrm{Ag}$ 作催化剂，加热，通入 $\mathrm{O_2}$
- 断键：醇的 $\alpha$ -C—H 和 O—H 断裂
- 官能团变化：$\mathrm{-CH_2OH \rightarrow -CHO}$（失氢）

**第二步：醛 → 酸**

- 条件：酸性 $\mathrm{KMnO_4}$、酸性 $\mathrm{K_2Cr_2O_7}$、银氨溶液、新制 $\mathrm{Cu(OH)_2}$ 等
- 官能团变化：$\mathrm{-CHO \rightarrow -COOH}$（得氧）

## 氧化产物的结构判断规律

**醇能否被催化氧化取决于是否有 $\alpha$ -H**：

| 醇的结构类型 | 是否有 $\alpha$ -H | 催化氧化产物 |
| :--- | :---: | :--- |
| 伯醇（$\mathrm{R-CH_2OH}$） | 有（2 个） | 醛 |
| 仲醇（$\mathrm{R-CH(OH)-R'}$） | 有（1 个） | 酮 |
| 叔醇（$\mathrm{R-C(OH)(R')-R''}$） | 无 | 不能催化氧化 |

**醛能否被继续氧化**：所有醛都能被氧化为羧酸（包括甲醛被氧化为 $\mathrm{CO_2}$）。

## 连续氧化的考题常见角度

1. 由醇的结构推断氧化产物（醛或酮）
2. 由氧化产物反推醇的结构
3. 多步氧化合成路线的设计
4. 醇、醛、酸的鉴别与分离

# 同分异构体计数

## 核心方法：基元法

**原理**：烃基的种数决定了其与特定基团相连所得同分异构体的种数。

**常见烃基种数**：

| 烃基 | 结构 | 种数 |
| :--- | :--- | :---: |
| 甲基 | $\mathrm{-CH_3}$ | 1 |
| 乙基 | $\mathrm{-CH_2CH_3}$ | 1 |
| 丙基 | $\mathrm{-C_3H_7}$ | 2 |
| 丁基 | $\mathrm{-C_4H_9}$ | 4 |
| 戊基 | $\mathrm{-C_5H_{11}}$ | 8 |

**应用示例**：
- $\mathrm{C_4H_9OH}$（丁醇）的种数 = 丁基的种数 = 4
- $\mathrm{C_5H_{11}CHO}$（己醛）的种数 = 戊基的种数 = 8（不考虑醛基位置）

## 核心方法：取代法

**原理**：将有机物视为母体上若干个 H 被取代，通过等效氢的种数确定取代产物的种数。

**步骤**：
1. 确定母体的等效氢种类数
2. 根据取代基个数，判断是否产生新异构

## 核心方法：插入法

**原理**：适用于在碳骨架中插入官能团（如酯基、醚键等）。

**步骤**：
1. 写出碳骨架
2. 确定官能团的插入位置
3. 删除对称重复

**例**：确定酯 $\mathrm{C_5H_{10}O_2}$ 的种数时，将酯基插入碳骨架的不同 $\mathrm{C-C}$ 键位置。

## 核心方法：等效氢法

**等效氢的判断规则**：
1. 同一碳原子上的 H 等效
2. 同一碳原子上甲基的 H 等效
3. 对称位置上的 H 等效

## 不饱和度的应用

**不饱和度（$\Omega$）公式**：
$$\Omega = \frac{2n_C + 2 - n_H - n_X + n_N}{2}$$

（含 O 时不影响不饱和度）

**不饱和度与结构的关系**：

| $\Omega$ | 可能结构 |
| :---: | :--- |
| 0 | 烷烃（链状饱和） |
| 1 | 一个双键或一个环 |
| 2 | 两个双键/一个三键/一个双键+一个环等 |
| 4 | 苯环 |

**应用**：由分子式快速判断可能含有的官能团类型。

# 官能团转化与保护

## 常见的官能团转化路线

**烯烃 → 醇**（水化）：
$$\mathrm{R-CH=CH_2 + H_2O \xrightarrow{H^+} R-CH(OH)-CH_3}$$

**烯烃 → 卤代烃**（加成）：
$$\mathrm{R-CH=CH_2 + HX \rightarrow R-CHX-CH_3}$$

**卤代烃 → 醇**（水解）：
$$\mathrm{R-X + NaOH \xrightarrow{H_2O} R-OH + NaX}$$

**醇 → 卤代烃**（取代）：
$$\mathrm{R-OH + HX \rightarrow R-X + H_2O}$$

**醇 → 烯烃**（消去）：
$$\mathrm{RCH_2-CH_2OH \xrightarrow{浓H_2SO_4, 170^\circ C} RCH=CH_2 + H_2O}$$

**醛 → 羧酸**（氧化）：
$$\mathrm{R-CHO \xrightarrow{[O]} R-COOH}$$

**羧酸 → 酯**（酯化）：
$$\mathrm{R-COOH + R'OH \rightleftharpoons R-COOR' + H_2O}$$

## 官能团保护的思路

当多官能团化合物需要选择性反应时，需要先保护某些官能团。

**常见保护策略**：

| 被保护基团 | 保护方法 | 保护目的 |
| :--- | :--- | :--- |
| 醇羟基（—OH） | 与乙酸酐形成酯 | 防止被氧化 |
| 醛基（—CHO） | 与乙二醇形成缩醛 | 防止在碱性条件下被氧化 |
| 酚羟基（$\mathrm{Ar-OH}$） | 与 $\mathrm{NaOH}$ 生成酚钠 | 防止被氧化或取代 |
| 碳碳双键（$\mathrm{C=C}$） | 与 $\mathrm{H_2}$ 加成 | 防止在氧化条件下被破坏 |

**保护策略在合成路线中的应用**：
- 先保护 → 进行所需反应 → 脱保护
- 选择保护基团时要考虑保护条件和脱保护条件的兼容性

# 多官能团物质的性质

## 官能团性质的独立性

在多官能团有机物中，各官能团通常**保持各自的性质**，可逐一分析，最后叠加。

**分析策略**：
1. 识别所有官能团
2. 分别列出各官能团能发生的反应
3. 综合判断整体性质

## 多官能团物质与常见试剂的反应汇总

| 试剂 | 反应的官能团 |
| :--- | :--- |
| $\mathrm{Na}$ | —OH（醇羟基、酚羟基）、—COOH |
| $\mathrm{NaOH}$ | —COOH、$\mathrm{Ar-OH}$、—COOR、$\mathrm{R-X}$ |
| $\mathrm{NaHCO_3}$ | —COOH |
| $\mathrm{Br_2}$（水溶液） | $\mathrm{C=C}$、$\mathrm{C\equiv C}$、—CHO、$\mathrm{Ar-OH}$（邻对位取代） |
| 银氨溶液/新制 $\mathrm{Cu(OH)_2}$ | —CHO |
| 酸性 $\mathrm{KMnO_4}$ | $\mathrm{C=C}$、—CHO、$\mathrm{R-CH_2OH}$、苯环侧链（有 $\alpha$ -H） |

## 与 $\mathrm{H_2}$ 加成的定量关系

| 官能团 | 与 $\mathrm{H_2}$ 反应比例 |
| :--- | :---: |
| 碳碳双键（$\mathrm{C=C}$） | $1:1$ |
| 碳碳三键（$\mathrm{C\equiv C}$） | $1:2$ |
| 醛基/羰基（$\mathrm{C=O}$） | $1:1$ |
| 苯环 | $1:3$（镍催化） |
| 酯基、羧基中的 $\mathrm{C=O}$ | 不反应（普通条件下） |

# 有机推断的综合思路

## 由反应条件推断官能团

| 反应条件 | 推断的官能团或结构 |
| :--- | :--- |
| $\mathrm{NaOH}$ 水溶液/加热 | 卤代烃水解（→醇）或酯水解 |
| $\mathrm{NaOH}$ 醇溶液/加热 | 卤代烃消去（→烯烃） |
| 浓 $\mathrm{H_2SO_4}$ /加热 | 醇消去（→烯烃）或酯化 |
| $\mathrm{Cu/O_2}$ /加热 | 醇氧化（伯→醛，仲→酮） |
| 银氨溶液/水浴加热 | 醛基 |
| 新制 $\mathrm{Cu(OH)_2}$ /加热 | 醛基（砖红色沉淀） |
| 酸性 $\mathrm{KMnO_4}$ | $\mathrm{C=C}$、$\mathrm{R-CH_2OH}$、醛基、苯环侧链 |
| 溴水 | $\mathrm{C=C}$、$\mathrm{C\equiv C}$、—CHO、苯酚邻对位取代 |
| $\mathrm{H_2/Ni}$ /加热 | $\mathrm{C=C}$、$\mathrm{C\equiv C}$、—CHO、羰基、苯环 |
| $\mathrm{HX}$ | 醇→卤代烃；烯烃加成 |
| $\mathrm{Na}$ | —OH（醇羟基、酚羟基）、—COOH |

# 题型总结

## 选择题常见考查角度

1. 官能团识别与性质判断
2. 特定试剂的反应对象（与 Na、NaOH、$\mathrm{NaHCO_3}$、溴水、$\mathrm{KMnO_4}$ 等）
3. 反应类型判断
4. 同分异构体计数
5. 有机反应条件判断
6. 有机物分子式与结构推断

## 填空题/推断题常见考查角度

1. 结构简式书写
2. 化学方程式书写（注意条件和配平）
3. 反应类型判断
4. 同分异构体书写
5. 合成路线设计

## 解题策略建议

1. **先识别官能团**：拿到有机物结构，首先圈出所有官能团
2. **再判断性质**：根据官能团列出所有可能发生的反应
3. **结合条件分析**：根据题目给出的条件确定发生了什么反应
4. **注意定量关系**：与 $\mathrm{H_2}$、$\mathrm{Na}$、$\mathrm{NaOH}$、银氨溶液、溴水等的计量关系
5. **熟练运用不饱和度**：快速判断分子式与结构的对应关系
