## Epic A · 身份、会话与账号安全

### US-A01 登录进入学习平台
**作为** 已注册的学习者或管理员，**我希望** 用用户名和密码登录，**以便** 进入与我身份匹配的界面。

- Given 我输入正确用户名与密码，When 提交登录，Then 服务端建立新会话并返回我的账户信息，页面进入首页或管理台。
- Given 密码错误或用户名不存在，When 提交，Then 返回 `401 invalid_credentials`，提示"用户名或密码错误"，不透露用户名是否存在。
- Given 我连续多次失败，When 超过来源地址限流阈值，Then 返回 `429 rate_limited`，并按 `Retry-After` 等待。
- 管理员登录后不得停留在学员端首页，应直接进入 `/admin`。

**关联**：FR-ACC-01/07；`POST /sessions`；`IdentityHttpContractTest`。

### US-A02 自助注册学习者账户
**作为** 新学员，**我希望** 自己注册一个账户，**以便** 之后由管理员为我开通内容。

- Given 用户名未被占用、密码 6–128 字符，When 注册，Then 账户建立并直接登录，且**没有任何文章授权**。
- Given 用户名已存在，When 注册，Then 返回 `409 username_conflict`，提示换一个用户名。
- 注册后首页显示空状态并引导联系管理员开通内容。

**关联**：FR-ACC-02；`POST /accounts`；`IdentityHttpContractTest`、`backendClient.test.js`。

### US-A03 刷新页面保持登录
**作为** 已登录用户，**我希望** 刷新或重新打开页面后仍是登录状态，**以便** 不重复输入密码。

- Given 我的服务端会话仍有效，When 打开任意需登录页面，Then 前端先查询 `/session` 并恢复账户、角色与授权。
- Given 会话已过期或被撤销，When 查询 `/session`，Then 返回 `401`，前端视为未登录并回到首页，而不是弹出错误。
- Given 我点击退出，When 请求 `DELETE /session`，Then 服务端撤销会话、清除 Cookie，前端回到未登录态。

**关联**：FR-ACC-03；`GET/DELETE /session`；`IdentityHttpContractTest`。

### US-A04 修改自己的密码
**作为** 已登录用户，**我希望** 在设置页修改密码，**以便** 保护账户。

- Given 我提供当前密码与新密码（6–128），When 保存，Then 修改成功，除当前会话外的旧会话全部失效。
- Given 当前密码错误，When 保存，Then 返回校验错误，密码不变。
- Given 新密码不符合长度，When 保存，Then 表单内联提示，不发送请求或返回 `400 validation_failed`。

**关联**：FR-ACC-04；`PUT /password`；`IdentityHttpContractTest`。

### US-A05 用激活码激活待激活账户（兼容能力）
**作为** 收到激活码的账户持有人，**我希望** 设置初始密码完成激活，**以便** 登录。

- Given 激活码有效、未使用、账户仍为 `pending_activation`，When 提交新密码，Then 账户转 `active`，激活码消费。
- Given 激活码已使用/过期/已撤销，When 提交，Then 返回 `401 invalid_activation_token`。
- 当前前端主流程使用"管理员直接设密码"，激活码接口保留但不作为默认入口。

**关联**：FR-ACC-05；`POST /account-activations/complete`；`IdentityHttpContractTest`。

### US-A06 写操作受 CSRF 保护
**作为** 系统，**我需要** 所有修改类请求带有效 CSRF token，**以便** 防止跨站伪造。

- Given 前端尚未取得 token，When 首次发出写请求，Then 先 `GET /csrf` 取 token，再带 `X-CSRF-TOKEN` 重试一次。
- Given 会话被轮换（登录、注册、进入学员账号），When 继续使用旧 token，Then 返回 `403 csrf_invalid`，前端必须丢弃内存 token 并重新获取。
- Given token 缺失，When 发出写请求，Then 请求被拒绝且不产生任何写入。

**关联**：FR-ACC-06；`/csrf`；`IdentityHttpContractTest`、`backendClient.test.js`。

### US-A07 申请教师账号并等待审核
**作为** 教师，**我希望** 在首页注册时勾选"我是教师"提交申请，**以便** 经超级管理员审核后获得管理员账号。

- Given 我在注册模式勾选"我是教师"，输入未被占用的用户名与 6–128 位密码，When 提交，Then 返回 `201` 与 `PENDING` 申请，页面提示等待审核，**不建立会话、不自动登录、不创建账户**。
- Given 用户名已有账户或已有待审核申请，When 提交，Then 返回 `409 username_conflict`，提示更换用户名。
- Given 我不勾选"我是教师"，When 注册，Then 仍按学习者流程立即建号并登录。
- 数据库只保存密码哈希；任何响应都不回显密码或哈希。

**关联**：FR-ACC-09；`POST /teacher-applications`；`IdentityHttpContractTest`、`teacherApplicationGateway.test.js`。

### US-A08 查看教师申请并通过审核
**作为** 超级管理员（`young`），**我希望** 看到待审核教师申请并通过合格申请，**以便** 让教师直接成为管理员。

- Given 我是超级管理员，When 打开"注册审核"，Then 可按待审核/已通过/已驳回/全部筛选，并看到待审核总数与提交时间。
- Given 我是普通管理员或学习者，When 访问审核列表或审核接口，Then 返回 `403 forbidden`，前端路由回到工作台。
- Given 我通过某条 `pending` 申请，When 确认，Then 同一事务创建 `role=administrator`、`status=active` 账户，申请转 `APPROVED`；申请人用原密码登录后角色为 `ADMINISTRATOR`、`superAdmin=false`，可进入管理台但不能审核教师申请。
- Given 申请已通过，When 再次通过，Then 返回 `409 state_conflict`；Given 用户名在建号时已被占用，Then 返回 `409 username_conflict` 且申请仍为 `pending`。

**关联**：FR-ACC-10/11/12；`GET /admin/teacher-applications`、`POST /admin/teacher-applications/{id}/approve`；`IdentityHttpContractTest`。

### US-A09 驳回教师申请并允许重新申请
**作为** 超级管理员，**我希望** 驳回不合格的教师申请并写明理由，**以便** 申请人修正后重新提交。

- Given 申请为 `pending`，When 我填写非空理由（≤500 字）并驳回，Then 申请转 `REJECTED`，记录审核人、时间与理由，**不创建账户**。
- Given 理由为空或只有空格，When 提交，Then 返回 `400 validation_failed`，申请保持 `pending`。
- Given 申请已被驳回，When 再次通过或驳回，Then 返回 `409 state_conflict`；同一用户名可以重新提交新的 `pending` 申请。
- 管理端列表显示驳回原因，便于追溯。

**关联**：FR-ACC-13；`POST /admin/teacher-applications/{id}/reject`；`IdentityHttpContractTest`、`teacherApplicationGateway.test.js`。

## Epic B · 学员管理与内容授权

### US-B01 查看我负责的学员
**作为** 管理员，**我希望** 看到学员列表及其授权、认领与最近动态，**以便** 判断今天该处理谁。

- Given 我打开学员页，When 列表加载，Then 每行显示用户名、已授权学科/篇数、认领归属、最近动态与测试标记。
- Given 学员较多，When 滚动加载下一页，Then 使用游标分页（默认 50/最大 100），不重复不丢行。
- 列表不得出现 `role=administrator` 的账户。

**关联**：FR-LRN-01；`GET /admin/learners`；`AdminLearnerHttpContractTest`。

### US-B02 新增一名测试学员
**作为** 管理员，**我希望** 通过新增入口创建测试学员，**以便** 在演示或验收时使用，而不影响真实统计。

- Given 我输入未被占用的用户名，When 新增，Then 创建 `isTest=true` 的学习者与待设密码账户，并且我自动成为其认领管理员。
- Given 新增成功，When 查看管理统计，Then 该学员不进入真实学员与活跃统计。
- Given 用户名冲突，When 新增，Then 返回 `409 username_conflict`，列表不新增行。
- 新增后该学员未设密码，登录应失败，直到我设置初始密码。

**关联**：FR-LRN-02；`POST /admin/learners`；`AdminLearnerHttpContractTest`。

### US-B03 认领与取消认领学员
**作为** 管理员，**我希望** 明确"这名学员由我负责"，**以便** 避免与他人重复操作。

- Given 学员无人认领，When 我认领，Then 认领关系建立，列表显示我的用户名。
- Given 学员已被我认领，When 再次认领，Then 幂等成功，不报错。
- Given 学员已被其他管理员认领，When 我认领，Then 返回 `409 learner_already_claimed`，提示先由对方取消认领。
- Given 我是认领人，When 取消认领，Then 认领清空；未认领时再次取消认领幂等返回 `204`。

**关联**：FR-LRN-03；`PUT/DELETE /admin/learners/{id}/claim`；`AdminLearnerHttpContractTest`。

### US-B04 删除不再使用的学员
**作为** 管理员，**我希望** 删除误建或已离开的学员，**以便** 清理数据。

- Given 学员由我认领且不是管理员关联账户、也不是特殊测试学员，When 删除并确认，Then 学员及其会话、作答、错题、签到、积分、卡片、任务成就记录一并删除。
- Given 学员未被认领或由他人认领，When 删除，Then 返回 `403 learner_not_claimed`（他人认领也可能是 `409 learner_already_claimed`），不删除任何数据。
- Given 学员是特殊测试学员，When 删除，Then 返回 `409 special_test_learner_protected`，列表不显示删除按钮。
- Given 学员关联管理员账户，When 删除，Then 返回 `409 administrator_learner_protected`。
- 删除是不可逆操作，必须二次确认并展示影响范围。

**关联**：FR-LRN-04；`DELETE /admin/learners/{id}`；`AdminLearnerHttpContractTest`。

### US-B05 先开通科目，再单独授权文章
**作为** 管理员，**我希望** 科目归属和具体文章授权分开操作，**以便** 先划定学员的学习范围，再逐篇决定看什么。

- Given 我在"学员科目"点击开通"化学"，When 保存，Then 只把"化学"写入 `enrolledSubjects`，该科下**没有任何文章被授权**，页面显示"已开通（未授权文章）"。
- Given 科目已开通但零授权，When 打开"权限管理"，Then 该学科仍可见，可逐篇勾选文章。
- Given 我只勾选部分文章，When 保存，Then 学科显示"部分文章已授权"，未勾选文章对学员不可见。
- Given 我取消"化学"科目，When 保存，Then 科目归属移除，并同步移除该科已授权文章。
- Given 另一名管理员也维护该学员，When 我保存，Then 只替换"我的课件"范围内的科目与授权，范围外既有权保留。
- Given 学员已登录，When 刷新，Then 首页与分类页只出现已授权文章；仅开通科目不会让文章出现。

**关联**：FR-LRN-05/07、FR-ADM-03；`PUT /admin/learners/{id}/content-grants`、`GET /me/content-grants`；`LearnerContentGrantHttpContractTest`、`adminSubjects.test.js`。

### US-B06 为学员设置初始密码/重置密码
**作为** 管理员，**我希望** 直接设定学员密码，**以便** 学员可以立即登录（不依赖激活码）。

- Given 学员为 `pending_activation` 且由我认领，When 我设置 6–128 字符密码，Then 账户转 `active`，可立即登录。
- Given 学员未被认领或由其他管理员认领，When 我设置密码，Then 返回 `403 learner_not_claimed`，不修改任何账户。
- Given 学员已有密码，When 我重置，Then 新密码生效，该学员所有旧会话与未使用激活码被撤销。
- Given 目标账户是独立管理员、已禁用或无学习者身份，When 我尝试设置，Then 请求被拒绝。

**关联**：FR-ACC-08；`PUT /admin/learners/{id}/password`；`AdminLearnerHttpContractTest`。

### US-B07 免密进入学员账号核对
**作为** 管理员，**我希望** 以该学员视角查看页面，**以便** 验证授权、题目和答案设置是否正确。

- Given 学员已激活、`role=learner` 且由我认领，When 我"进入账号"，Then 建立学员会话并进入学员端，管理员原会话不被撤销。
- Given 学员未被认领或由其他管理员认领，When 尝试进入，Then 返回 `403 learner_not_claimed`。
- Given 我退出学员会话并重新登录管理员，Then 可继续管理操作。
- Given 目标未激活或是管理员账户，When 尝试进入，Then 请求被拒绝。

**关联**：FR-LRN-06；`POST /admin/learners/{id}/impersonate`；`IdentityHttpContractTest`。

### US-B08 未认领学员不可被管理
**作为** 管理员，**我希望** 未认领或由他人认领的学员在页面上不可操作，**以便** 从入口就避免越权。

- Given 学员未被认领，When 查看学生账户列表，Then "查看详情/设置密码/进入账号/删除"均不可用，并提示先认领。
- Given 学员由其他管理员认领，When 查看，Then 管理按钮同样不可用，并显示对方用户名。
- Given 学员由我认领，When 查看，Then 上述按钮恢复可用；特殊测试学员仍不显示删除按钮。
- 即使绕过前端直接调用接口，服务端也返回 `403 learner_not_claimed`。

**关联**：FR-LRN-03/04/06、FR-ACC-08、FR-ADM-03；`AdminLearnerHttpContractTest`、`IdentityHttpContractTest`、`AdminAnalyticsHttpContractTest`。

## Epic C · 课件目录与认领

### US-C01 同步静态课件目录
**作为** 管理员，**我希望** 平台知道每篇文章属于哪个学科，**以便** 按学科认领和统计。

- Given 前端加载文章索引，When 打开管理台，Then 自动 `POST /admin/courseware-catalog/sync`，把 `articleId → 学科/标题` 幂等写入。
- Given 新增了文章，When 再次同步，Then 只新增/更新对应行，不删除既有认领。
- 同步失败不应阻断页面其他功能，但要提示"课件目录未同步"。

**关联**：FR-CW-01；`POST /admin/courseware-catalog/sync`；`CoursewareClaimHttpContractTest`。

### US-C02 认领一个学科
**作为** 管理员，**我希望** 认领整科，**以便** 该科现有与未来新增课件都归我维护。

- Given 我认领"英语"，When 查看"我的课件"，Then 英语全部文章出现，包括之后新增的文章。
- Given 两名管理员都认领"英语"，When 各自查看，Then 都可维护，互不独占。
- Given 我释放"英语"，When 查看，Then 仅靠学科覆盖的课件回到待认领，我单独认领的课件仍保留；该科放弃记录不被自动撤销。
- Given 我重新认领"英语"，Then 该科单篇排除与放弃记录一并清理，全部课件恢复可见。

**关联**：FR-CW-02；`PUT/DELETE /admin/courseware-claims/subjects/{subject}`；`CoursewareClaimHttpContractTest`。

### US-C03 在学科覆盖下单独释放一篇课件
**作为** 管理员，**我希望** 把某篇不需要我维护的文章移出"我的课件"，**以便** 聚焦自己的范围。

- Given "化学"由我认领，When 我释放其中一篇，Then 该篇带排除标记，从我的业务页消失并回到待认领。
- Given 该篇已被我排除，When 我重新单篇认领，Then 排除清除，该篇恢复在我的课件中。
- Given 该篇已被我放弃，When 我重新单篇认领，Then 放弃记录清除，该篇恢复可见。
- Given 我重新认领整个学科，Then 该科全部排除与放弃记录被清理。

**关联**：FR-CW-03；`PUT/DELETE /admin/courseware-claims/articles/{articleId}`；`CoursewareClaimHttpContractTest`。

### US-C04 查看课件认领目录
**作为** 管理员，**我希望** 看到"我的/待认领/已放弃/全部"四种视图，**以便** 规划工作量。

- Given 我选择"我的"，When 加载，Then 只显示我认领学科下未被排除、未被放弃的课件与单篇认领课件，并标注来源（学科/单篇）。

- Given 限时任务未接取，When 点击"接取"，Then 服务端记录开始与截止时间，页面显示倒计时。
- Given 已接取，Then 再次接取返回 `409 task_already_accepted`。
- Given 已过期，Then 显示 `409 task_expired` 并允许重新接取。

**关联**：FR-GRW-05；`POST /tasks/{key}/accept`；`TaskCatalogTest`。

### US-I05 领取任务奖励
**作为** 学习者，**我希望** 完成后领取积分，**以便** 闭环。

- Given 任务完成且本期未领，When 领取，Then 积分增加，本期标记已领。
- Given 未完成，Then `409 task_not_completed`；未接取，Then `409 task_not_accepted`；重复领取，Then `409 task_already_claimed`。
- 领取与积分累加在同一事务，刷新后状态一致。

**关联**：FR-GRW-06；`POST /tasks/{key}/claims`；`TaskCatalogTest`。

## Epic J · 管理端统计与学员详情

### US-J01 一眼掌握工作台概览
**作为** 管理员，**我希望** 登录后看到我的学员数、活跃、待批阅与近期提交，**以便** 安排今天的批阅。

- Given 打开工作台，Then 显示**四项指标**：我的学员/总学员（同一张卡）、近 7 天活跃、待批阅、近 7 日提交，**不显示待认领课件**。
- 学习类指标只统计"我的课件"，学员计数与积分/签到为全局口径；测试学员的待批阅、提交与活跃不计入。
- 统计接口失败时展示错误提示并保留已加载指标，不白屏。

**关联**：FR-ADM-01/04；`GET /admin/analytics/overview`；`AdminAnalyticsHttpContractTest`。

### US-J02 查看 30 天趋势
**作为** 管理员，**我希望** 看到每日提交与批阅趋势，**以便** 判断学员活跃变化。

- Given 打开趋势图，Then 显示近 30 天每日提交/批阅点，缺失日期补零。
- Given 我切换 7/90 天，Then 数据按选择重算，只含"我的课件"。
- 测试学员不计入趋势。

**关联**：FR-ADM-02；`GET /admin/analytics/activity?days=`；`AdminAnalyticsHttpContractTest`。

### US-J03 打开学员详情抽屉
**作为** 管理员，**我希望** 点开一名学员看积分、签到、分学科进度与最近作答，**以便** 做针对性沟通。

- Given 我点击学员行，Then 抽屉显示积分/累计/等级、近 30 天签到、分学科完成度、最近 10 条作答与 30 天动态。
- 学习数据只含"我的课件"；范围外文章不出现在进度与最近作答。
- Given 学员为测试学员，Then 明确标注，避免误判为真实学员。

**关联**：FR-ADM-03/04；`GET /admin/learners/{id}/profile`；`AdminAnalyticsHttpContractTest`。

### US-J04 从“去批阅”直达具体习题
**作为** 管理员，**我希望** 在工作台点“去批阅”后直接落到最早一条待批阅习题，**以便** 少点几次、马上开始批阅。

- Given 概览返回有效 `pendingReviewTarget`，When 点击“去批阅”，Then 进入 `/admin/reviews` 并携带 `studentId/articleId/questionId/filter=pending`，自动选中该学员、打开该文章、筛选待批阅并滚动高亮该题。
- Given 没有待批阅（目标为 `null`），When 点击，Then 只打开批阅页，由我自行选择学员与课件。
- 目标习题不在当前管理员可见课件范围内时，不生成深链，回到普通批阅入口。
- 深链只定位界面，不改变任何作答或批阅状态。

**关联**：FR-ADM-01/04；`GET /admin/analytics/overview`、`/admin/reviews`；`AdminAnalyticsHttpContractTest`、`analytics.test.js`。

## Epic K · 测试学员机制

### US-K01 标记测试学员并从统计中排除
**作为** 管理员/验收人员，**我希望** 测试账户不污染真实统计，**以便** 数据可信。

- Given 某学员 `is_test=true`，When 查看概览与趋势，Then 其**待批阅、近 7 日提交、活跃度、趋势与待批阅直达目标全部不计入**。
- Given 我在学员切换器查看，Then 测试学员单独分组展示。
- 测试学员仍可正常登录、作答、签到与抽卡。

**关联**：FR-TST-01/04；`GET /admin/learners`、analytics；`TestLearnerHttpContractTest`。

### US-K02 使用特殊测试学员做全链路验收
**作为** 验收人员，**我希望** 有一个拥有全部课件与高积分的账户，**以便** 一次性跑通所有功能。

- Given 登录特殊测试学员，Then 可见全部文章（`allArticles=true`），积分固定 `999999999`，抽卡不扣分。
- Given 全库最多一个该账户，Then 重复标记被数据库唯一索引阻止。
- 该账户不参与统计，不影响真实学员数据。

**关联**：FR-TST-02；`GET /me/content-grants`、`GET /rewards`；`TestLearnerHttpContractTest`、`FlywayMigrationTest`。

### US-K03 特殊测试学员不可删除
**作为** 平台，**我需要** 保护唯一且拥有全量能力的特殊测试学员，**以便** 验收环境始终可用。

- Given 我在学员列表查看特殊测试学员，Then 不显示"删除学员"按钮。
- Given 我绕过前端调用 `DELETE /admin/learners/{id}`，Then 返回 `409 special_test_learner_protected`，数据保持不变。

**关联**：FR-TST-03；`DELETE /admin/learners/{id}`；`AdminLearnerHttpContractTest`。

## Epic L · 运行、发布与数据治理

### US-L01 查询系统状态
**作为** 运维/前端，**我希望** 有一个稳定的状态接口，**以便** 确认服务版本与可用性。

- Given 服务正常，Then `GET /system/status` 返回 `status=ok`、`service`、`version`、`time`。
- Given 版本未知，Then `version=dev`，不得硬编码生产 commit。
- 响应不含 profile、hostname、数据库信息或 secret。

**关联**：FR-SYS-01；`GET /system/status`；`SystemHttpContractTest`。

### US-L02 用健康检查阻断坏发布
**作为** 运维，**我希望** 发布前验证依赖，**以便** 不让坏版本接流量。

- Given 数据库不可达，When 检查 readiness，Then 返回失败，发布流程停止并保留旧版本。
- Given 进程存活，Then liveness 返回 UP。
- readiness 检查不得执行昂贵查询。

**关联**：FR-SYS-02；`/actuator/health/*`；CI/CD 工作流。

### US-L03 从空库或存量库安全升级
**作为** 运维，**我希望** 迁移在两种库上都成功，**以便** 不因"对象已存在"阻塞上线。

- Given 空 PostgreSQL 17，When 执行 Flyway，Then V1→V19 全部成功，第二次 migrate 执行 0 步。
- Given 存量 Supabase 已手工对齐部分对象，When 执行 V11/V12/V15/V16/V17/V18/V19，Then 幂等成功。
- 运行角色由 provision 脚本授予 DML 与 RLS，应用账户无 DDL 权限。

**关联**：FR-SYS-03；`FlywayMigrationTest`、`database/reconciliation/*`。

### US-L04 发布前扫描密钥与审计权限
**作为** 运维，**我希望** 阻止 secret 进入仓库并核对数据库权限，**以便** 降低泄露与越权风险。

- Given 提交中含疑似密钥，When 运行 `npm run test:secrets`，Then 构建失败并指出文件。
- Given 运行角色权限或浏览器表权限不符，When 执行审计 SQL，Then `anomaly_count` 非 0，必须修复后再发布。
- 浏览器角色对业务表的直写权限只在新前端验证通过后撤销。

**关联**：FR-SYS-04、NFR-SEC-07；`scripts/ci/scan-tracked-secrets.mjs`、`database/audit/*`。
