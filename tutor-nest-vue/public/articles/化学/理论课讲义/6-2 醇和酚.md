# 醇

## 概念

醇是羟基与烃基相连的化合物（脂肪醇，如 $\mathrm{CH_3CH_2OH}$）或羟基与苯环侧链上的碳原子相连的化合物（芳香醇，如 $\mathrm{C_6H_5CH_2OH}$）。饱和一元醇的通式为 $\mathrm{C_nH_{2n+1}OH}$（$n \ge 1$）。

## 物理性质变化规律

| 物理性质 | 变化规律                                                      |
| :--- | :-------------------------------------------------------- |
| 密度   | 一元脂肪醇的密度一般小于水（$1\ \mathrm{g \cdot cm^{-3}}$）              |
| 沸点   | ①直链饱和一元醇的沸点随碳原子数增多而升高；②醇分子间存在氢键，相对分子质量相近的醇和烷烃相比，醇的沸点远高于烷烃 |
| 水溶性  | 低级脂肪醇易溶于水（$\mathrm{C} \le 3$），饱和一元醇的溶解度随碳原子数增多而逐渐减小       |

**注**：醇由羟基（亲水基）和烃基（憎水基）组成，每个亲水基一般能促进 3 个碳以内的烃基溶解，当憎水基碳架太大或太长，以憎水为主。

## 化学性质——以乙醇为例

醇的官能团为羟基（—OH），受羟基的影响，C—H 的极性增强，一定条件下也可能断键发生化学反应。乙醇发生化学反应时，可断裂不同的化学键。

**与钠反应（置换反应）**：分子中 a 键断裂，化学方程式为：
$$2\mathrm{CH_3CH_2OH + 2Na \rightarrow 2CH_3CH_2ONa + H_2 \uparrow}$$

**注**：有机化合物中的羟基 H 原子均能与钾、钙、钠等发生置换反应。

**消去反应**：乙醇在浓硫酸作用下，加热到 $170^\circ\mathrm{C}$，发生消去反应生成乙烯。分子中 b、d 键断裂：
$$\mathrm{CH_3CH_2OH \xrightarrow{浓H_2SO_4, 170^\circ C} CH_2=CH_2 \uparrow + H_2O}$$

**注**：
- 醇必须要有 $\beta$ -H 才能发生消去反应，且 $\beta$ -H 不能是苯环上的 H。
- 醇发生消去反应脱去水分子，需要浓硫酸吸水促进消去反应正向进行。

**取代反应**

**（1）与卤化氢（HX）发生取代反应**：分子中 b 键断裂：
$$\mathrm{C_2H_5OH + HX \rightarrow C_2H_5X + H_2O}$$

**（2）分子间脱水成醚**：一分子中 a 键断裂，另一分子中 b 键断裂：
$$2\mathrm{C_2H_5OH \xrightarrow{浓H_2SO_4, 140^\circ C} C_2H_5OC_2H_5 + H_2O}$$

**（3）与含氧酸发生酯化反应（酸脱羟基，醇脱氢）**：醇断 a 键：
$$\mathrm{CH_3COOH + C_2H_5OH \rightleftharpoons CH_3COOC_2H_5 + H_2O}$$

**氧化反应**

**（1）燃烧反应**：
$$\mathrm{C_2H_5OH + 3O_2 \xrightarrow{点燃} 2CO_2 + 3H_2O}$$

**注**：计算烃的含氧衍生物完全燃烧的耗氧量，需先将分子中的 O 原子组合成 $\mathrm{CO_2}$ 或 $\mathrm{H_2O}$，再对剩余部分进行耗氧分析。

**（2）催化氧化**：乙醇在铜或银作催化剂、加热条件下与氧气反应生成乙醛，分子中 a、c 键断裂：
$$2\mathrm{CH_3CH_2OH + O_2 \xrightarrow{Cu, \triangle} 2CH_3CHO + 2H_2O}$$

**注**：醇的催化氧化特征是“失氢”。

**（3）酸性 $\mathrm{K_2Cr_2O_7}$ 溶液（或酸性 $\mathrm{KMnO_4}$ 溶液）**：
- 乙醇能被酸性重铬酸钾溶液氧化，溶液颜色由橙色变成灰绿色（酒驾测试仪器的工作原理）
- 氧化过程分为两个阶段：$\mathrm{CH_3CH_2OH \rightarrow CH_3CHO \rightarrow CH_3COOH}$
- 乙醇也能被酸性高锰酸钾溶液氧化成乙酸，使溶液褪色

## 醇的氧化和消去反应规律

**α-H**：与官能团相连的碳原子上的氢原子。

**β-H**：与官能团相连的碳原子的相邻碳原子上的氢原子。

**醇能否发生催化氧化及氧化产物类型**取决于醇分子中是否有 α-H 及其个数：

| α-H 个数 | 催化氧化产物 |
| :---: | :--- |
| 0 | 不能发生催化氧化 |
| 1 | 酮 |
| 2 个及以上 | 醛 |

**注**：羟基在链端，被催化氧化成醛；羟基在链中，被催化氧化成酮，或不能发生催化氧化。

**醇能否被酸性高锰酸钾或重铬酸钾溶液氧化**取决于醇分子中是否有 α-H 及其个数：
- 无 α-H：不能氧化
- 1 个 α-H：被氧化成酮
- 2 个 α-H：被氧化成羧酸
- 3 个 α-H：被氧化成 $\mathrm{CO_2}$

**醇消去反应的条件**：
- 若醇分子中只有一个碳原子或无 β-H（β 碳原子上没有 H 原子），则不能发生消去反应
- 如 $\mathrm{CH_3OH}$、$\mathrm{C(CH_3)_3CH_2OH}$ 不能发生消去反应
- 某些醇发生消去反应，可以生成不同的烯烃

**卤代烃、醇发生消去反应的对比**：

| 研究对象 | 卤代烃 | 醇 |
| :--- | :--- | :--- |
| 断键位置 | $\beta$ -C—H 和 C—X | $\beta$ -C—H 和 C—OH |
| 注 | $\beta$ -C—H 不能是苯环上的 C—H |
| 脱出的小分子 | HX | $\mathrm{H_2O}$ |
| 反应条件 | NaOH（或其他强碱）醇溶液、加热 | 浓硫酸、加热 |
| 作用 | NaOH 消耗 HX 促进平衡正向移动 | 浓硫酸吸水促进平衡正向移动 |

# 酚

## 概念

酚是羟基与苯环直接相连而形成的化合物，最简单的酚类化合物为苯酚（）。

## 苯酚的物理性质

- 无色晶体，有特殊气味
- 常温下微溶于水，温度高于 $65^\circ\mathrm{C}$ 时与水混溶
- 易溶于有机溶剂
- 有毒，有腐蚀性

## 苯酚的化学性质

**弱酸性（苯酚俗称石炭酸）**：受苯环的影响，苯酚分子中的氢氧键更容易断裂，因此苯酚能在水溶液中发生微弱电离产生 $\mathrm{H^+}$：
$$\mathrm{C_6H_5OH \rightleftharpoons C_6H_5O^- + H^+}$$

**酸性强弱顺序**：$\mathrm{H_2CO_3 > C_6H_5OH > HCO_3^-}$

苯酚不能使酸碱指示剂变色，其酸性仅表现在与活泼金属、强碱以及某些盐（如 $\mathrm{Na_2CO_3}$）的反应中。

**（1）与 NaOH 反应**：
$$\mathrm{C_6H_5OH + NaOH \rightarrow C_6H_5ONa + H_2O}$$

**（2）与 $\mathrm{Na_2CO_3}$ 反应**（无论苯酚少量还是过量，都生成 $\mathrm{NaHCO_3}$）：
$$\mathrm{C_6H_5OH + Na_2CO_3 \rightarrow C_6H_5ONa + NaHCO_3}$$

**（3）与 $\mathrm{NaHCO_3}$ 不反应**：因酸性 $\mathrm{H_2CO_3 > C_6H_5OH}$，苯酚不能制碳酸。

**与溴水的取代反应**：苯酚滴入过量浓溴水中的现象为生成白色沉淀。
$$\mathrm{C_6H_5OH + 3Br_2 \rightarrow C_6H_2Br_3OH \downarrow + 3HBr}$$

**注**：卤素单质参与的有机反应总结：

| 卤素种类 | 状态 | 有机化合物种类 | 反应条件 | 反应类型 |
| :--- | :--- | :--- | :--- | :--- |
| $\mathrm{Cl_2}$ | 气态 | 烷基 | 光照 | 取代反应 |
| $\mathrm{Br_2}$ | 气态 | 烷基 | 光照 | 取代反应 |
| $\mathrm{Br_2}$ | 液态 | 不含酚羟基的苯基 | 催化剂（$\mathrm{FeBr_3}$） | 取代反应 |
| $\mathrm{Br_2}$ | 水溶液 | 碳碳双键、碳碳三键 | 无 | 加成反应 |
| $\mathrm{Br_2}$ | 水溶液 | 醛基 | 无 | 氧化反应 |
| $\mathrm{Br_2}$ | 水溶液 | 苯酚（酚羟基邻、对位氢） | 无 | 取代反应 |
| $\mathrm{Br_2}$ | $\mathrm{CCl_4}$ 溶液 | 碳碳双键、碳碳三键 | 无 | 加成反应 |

**显色反应**：苯酚与 $\mathrm{FeCl_3}$ 溶液作用显紫色（可用于鉴别苯酚）。

**缩聚反应**：苯酚与甲醛在催化剂作用下，可发生缩聚反应生成酚醛树脂：
$$n\mathrm{C_6H_5OH} + n\mathrm{HCHO} \xrightarrow{催化剂} \mathrm{[C_6H_3OHCH_2]_n} + n\mathrm{H_2O}$$

**氧化反应**：苯酚易被空气氧化为粉红色物质，也可以燃烧，还能被酸性高锰酸钾氧化。
