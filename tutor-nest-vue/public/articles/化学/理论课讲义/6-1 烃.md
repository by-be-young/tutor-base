# 烷烃

## 组成、结构特点和通式

**通式**：$\mathrm{C_nH_{2n+2}}$（链状烷烃）

**结构特点**：
- 碳原子全部为 $\mathrm{sp^3}$ 杂化
- 碳原子与碳原子或其他原子之间全部形成 σ 键（单键）
- 碳原子呈四面体构型，键角约为 $109^\circ 28'$
- 烷烃分子中的共价键全部是单键，碳碳键为非极性键，碳氢键为极性键

## 物理性质变化规律

| 性质 | 变化规律 |
| :--- | :--- |
| 状态 | 标准状况下，含 1～4 个碳原子的烃为气态；含 5～16 个碳原子的烃为液态；含 17 个碳原子以上的烃为固态 |
| 沸点 | 碳原子数增多，沸点升高；碳原子数相同的同分异构体，支链越多，沸点越低（如：正戊烷 > 异戊烷 > 新戊烷） |
| 相对密度 | 碳原子数增多，相对密度逐渐增大，但均比水小 |
| 水溶性 | 均难溶于水，易溶于有机溶剂 |

## 化学性质

### 1. 取代反应

**定义**：有机化合物分子中某些原子或原子团被其他原子或原子团所替代的反应。

**化学键变化特征**：“断 σ 成 σ”——断裂一个 σ 键，形成一个 σ 键。

**烷烃的卤代反应**：
- 反应条件：烷烃与气态卤素单质在光照下反应（常温、光照）
- 反应通式：$\mathrm{R-H + X_2 \xrightarrow{光照} R-X + HX}$
- 产物成分：多种卤代烃的混合物 + HX（因反应可连续进行，难以得到纯净的一取代产物）
- 定量关系：取代 $1\ \mathrm{mol}$ H 原子，消耗 $1\ \mathrm{mol}$ 卤素单质，生成 $1\ \mathrm{mol}$ HX

**甲烷的氯代反应**（分步进行）：
- $\mathrm{CH_4 + Cl_2 \xrightarrow{光照} CH_3Cl + HCl}$（一氯甲烷）
- $\mathrm{CH_3Cl + Cl_2 \xrightarrow{光照} CH_2Cl_2 + HCl}$（二氯甲烷）
- $\mathrm{CH_2Cl_2 + Cl_2 \xrightarrow{光照} CHCl_3 + HCl}$（三氯甲烷，俗称氯仿）
- $\mathrm{CHCl_3 + Cl_2 \xrightarrow{光照} CCl_4 + HCl}$（四氯化碳）

**注**：
- 甲烷与氯气的取代反应是分步进行的，各步反应同时发生，因此产物是四种氯代甲烷的混合物
- 绝大多数有机反应都伴随着副反应，所以很难得到纯净物
- 甲烷的二氯代物只有一种，可证明甲烷为正四面体结构（若为平面正方形结构，二氯代物有 2 种）

### 2. 氧化反应（燃烧）

烷烃完全燃烧的通式：
$$\mathrm{C_nH_{2n+2} + \frac{3n+1}{2}O_2 \xrightarrow{点燃} nCO_2 + (n+1)H_2O}$$

烷烃燃烧现象：火焰较明亮（随碳原子数增多，火焰明亮程度增加，伴有黑烟）

**注**：烷烃不能使酸性 $\mathrm{KMnO_4}$ 溶液褪色，也不能与溴水反应。

### 3. 裂化与裂解

- **裂化**：在加热、加压和催化剂条件下，将长链烷烃断裂成短链的烷烃和烯烃
  - 如：$\mathrm{C_{16}H_{34} \xrightarrow{催化剂} C_8H_{18} + C_8H_{16}}$
- **裂解**：深度裂化，产物为碳原子数更小的烃

### 4. 催化重整

在催化剂作用下，烷烃分子结构重新排列，可转化为芳香烃或支链烷烃，是生产高辛烷值汽油的重要方法。

## 常见烷烃的同分异构体数目

| 分子式 | 同分异构体数目 |
| :---: | :---: |
| $\mathrm{CH_4}$、$\mathrm{C_2H_6}$、$\mathrm{C_3H_8}$ | 1 |
| $\mathrm{C_4H_{10}}$ | 2（正丁烷、异丁烷） |
| $\mathrm{C_5H_{12}}$ | 3（正戊烷、异戊烷、新戊烷） |
| $\mathrm{C_6H_{14}}$ | 5 |
| $\mathrm{C_7H_{16}}$ | 9 |

# 烯烃

## 组成、结构特点和通式

**通式**：$\mathrm{C_nH_{2n}}$（含一个碳碳双键的链状烯烃）

**结构特点**：
- 含有一个碳碳双键（$\mathrm{C=C}$），不饱和度为 1
- 碳碳双键中：1 个 σ 键（$\mathrm{sp^2}$ 杂化轨道“头碰头”重叠）+ 1 个 π 键（p 轨道“肩并肩”重叠）
- 碳碳双键上的碳原子为 $\mathrm{sp^2}$ 杂化，键角约为 $120^\circ$，呈平面构型
- 与碳碳双键直接相连的 6 个原子（2 个双键碳原子及其直接相连的 4 个原子）共平面
- $\mathrm{C=C}$ 键长小于 $\mathrm{C-C}$ 键长，双键不能自由旋转（导致顺反异构）

## 物理性质变化规律

| 性质 | 变化规律 |
| :--- | :--- |
| 状态 | 标准状况下，含 2～4 个碳原子的烯烃为气态；含 5 个碳原子以上为液态或固态 |
| 沸点 | 碳原子数增多，沸点升高；同分异构体中支链越多，沸点越低 |
| 相对密度 | 碳原子数增多，相对密度增大，均比水小 |
| 水溶性 | 难溶于水，易溶于有机溶剂 |

## 顺反异构

**产生条件**：
1. 分子中存在碳碳双键
2. 每个双键碳上连接的两个原子或原子团不同

**顺反异构体**：
- **顺式**：两个相同的原子或原子团在碳碳双键的同一侧
- **反式**：两个相同的原子或原子团在碳碳双键的两侧

**性质差异**：顺反异构体的物理性质（熔点、沸点、溶解度等）不同，化学性质相似。

## 化学性质

### 1. 加成反应

**定义**：不饱和碳原子与其他原子或原子团直接结合生成新化合物的反应。

**化学键变化特征**：“断 π 成 σ”——π 键断裂，形成两个新的 σ 键。

#### （1）催化加氢

$$\mathrm{R-CH=CH-R' + H_2 \xrightarrow{Ni} R-CH_2-CH_2-R'}$$

烯烃与氢气在催化剂（Ni、Pt、Pd）作用下发生加成反应，生成烷烃。

#### （2）与卤素加成

$$\mathrm{R-CH=CH-R' + X_2 \rightarrow R-CHX-CHX-R'}$$

烯烃能使溴的四氯化碳溶液或溴水褪色，可用于鉴别烯烃。

#### （3）与卤化氢加成

$$\mathrm{R-CH=CH_2 + HX \rightarrow R-CHX-CH_3}$$

**马氏规则**：不对称烯烃与不对称含氢物质（HX、$\mathrm{H_2O}$ 等）加成时，H 原子加到含氢较多的不饱和碳原子上。

- 例：$\mathrm{CH_3-CH=CH_2 + HBr \xrightarrow{主要} CH_3-CHBr-CH_3}$（2-溴丙烷）
- 次要产物：$\mathrm{CH_3-CH_2-CH_2Br}$（1-溴丙烷）

**反马氏加成**：在过氧化物存在下，H 原子加到含氢较少的不饱和碳原子上。

- 例：$\mathrm{CH_3-CH=CH_2 + HBr \xrightarrow{过氧化物} CH_3-CH_2-CH_2Br}$

**注**：仅 $\mathrm{HBr}$ 存在过氧化物效应，$\mathrm{HCl}$、$\mathrm{HI}$ 不适用。

#### （4）与水加成（工业制醇）

$$\mathrm{CH_2=CH_2 + H_2O \xrightarrow{催化剂} CH_3CH_2OH}$$

#### （5）与硫酸加成

$$\mathrm{CH_2=CH_2 + H_2SO_4 \rightarrow CH_3CH_2OSO_3H \xrightarrow{H_2O} CH_3CH_2OH}$$

间接水合法，工业制乙醇的重要方法。

### 2. 氧化反应

#### （1）燃烧

烯烃完全燃烧的通式：
$$\mathrm{C_nH_{2n} + \frac{3n}{2}O_2 \xrightarrow{点燃} nCO_2 + nH_2O}$$

烯烃燃烧现象：火焰明亮，伴有黑烟（含碳量较高，燃烧不充分）。

#### （2）被酸性 $\mathrm{KMnO_4}$ 溶液氧化

烯烃能使酸性 $\mathrm{KMnO_4}$ 溶液褪色，可用于鉴别烯烃。

**氧化规律**：

| 双键碳上的氢原子数 | 氧化产物 |
| :---: | :--- |
| 2 个 H | $\mathrm{CO_2}$ |
| 1 个 H | 羧基（—COOH） |
| 0 个 H | 酮羰基（$\mathrm{C=O}$） |

**应用**：通过氧化产物的结构可推断原烯烃的结构。

### 3. 加聚反应

烯烃在一定条件下发生加聚反应生成高分子化合物。

**乙烯的加聚**：
$$\mathrm{nCH_2=CH_2 \xrightarrow{催化剂} [-CH_2-CH_2-]_n}$$

**丙烯的加聚**：
$$\mathrm{nCH_3-CH=CH_2 \xrightarrow{催化剂} [-CH_2-CH(CH_3)-]_n}$$

**注**：
- 加聚反应的单体必须含有不饱和键（碳碳双键或碳碳三键）
- 聚丙烯中不存在不饱和键，不能使酸性 $\mathrm{KMnO_4}$ 溶液褪色

### 4. 共轭二烯烃的特殊反应

**共轭二烯烃**：两个碳碳双键被一个碳碳单键隔开的二烯烃。

**1,2-加成**：与普通烯烃相同，两个双键分别加成。
**1,4-加成**：两个双键两端的碳原子与试剂结合，中间两个碳原子形成新的双键。

**第尔斯-阿尔德反应（D-A 反应）**：
- 共轭二烯烃与含碳碳双键或三键的化合物发生 1,4-加成反应
- 可构建六元环状碳骨架
- 是合成六元环化合物的重要方法

# 炔烃

## 组成、结构特点和通式

**通式**：$\mathrm{C_nH_{2n-2}}$（含一个碳碳三键的链状炔烃）

**结构特点**：
- 含有一个碳碳三键（$\mathrm{C \equiv C}$），不饱和度为 2
- 碳碳三键中：1 个 σ 键（$\mathrm{sp}$ 杂化轨道“头碰头”重叠）+ 2 个 π 键（p 轨道“肩并肩”重叠）
- 三键碳原子为 $\mathrm{sp}$ 杂化，键角为 $180^\circ$，呈直线构型
- 与碳碳三键直接相连的原子共直线
- 三键碳原子与两端原子所构成的体系为直线形

## 物理性质变化规律

| 性质 | 变化规律 |
| :--- | :--- |
| 状态 | 标准状况下，含 2～4 个碳原子的炔烃为气态；含 5 个碳原子以上为液态或固态 |
| 沸点 | 碳原子数增多，沸点升高 |
| 相对密度 | 碳原子数增多，相对密度增大，均比水小 |
| 水溶性 | 难溶于水，易溶于有机溶剂 |

## 化学性质

### 1. 加成反应

**定义**：不饱和碳原子与其他原子或原子团直接结合生成新化合物的反应。

#### （1）催化加氢

炔烃与氢气在催化剂作用下逐步加成：

$$\mathrm{R-C \equiv C-R' + H_2 \xrightarrow{Ni} R-CH=CH-R'}$$

$$\mathrm{R-CH=CH-R' + H_2 \xrightarrow{Ni} R-CH_2-CH_2-R'}$$

**定量关系**：$1\ \mathrm{mol}$ 碳碳三键最多与 $2\ \mathrm{mol}\ \mathrm{H_2}$ 加成。

#### （2）与卤素加成

$$\mathrm{R-C \equiv C-R' + X_2 \rightarrow R-CX=CX-R'}$$

$$\mathrm{R-CX=CX-R' + X_2 \rightarrow R-CX_2-CX_2-R'}$$

**定量关系**：$1\ \mathrm{mol}$ 碳碳三键最多与 $2\ \mathrm{mol}\ \mathrm{X_2}$ 加成。

炔烃能使溴的四氯化碳溶液或溴水褪色（先慢后快，比烯烃与溴的反应慢）。

#### （3）与卤化氢加成

$$\mathrm{R-C \equiv CH + HX \rightarrow R-CX=CH_2}$$

$$\mathrm{R-CX=CH_2 + HX \rightarrow R-CX_2-CH_3}$$

遵循马氏规则：H 原子加到含氢较多的三键碳上。

#### （4）与水加成（乙炔水化制乙醛）

$$\mathrm{HC \equiv CH + H_2O \xrightarrow{HgSO_4} CH_3CHO}$$

乙炔与水的加成反应在汞盐催化下生成乙醛（烯醇重排）。

**烯醇重排**：$\mathrm{HC=CH-OH \rightarrow CH_3CHO}$（羟基在双键碳上的结构不稳定，重排为羰基化合物）

### 2. 氧化反应

#### （1）燃烧

炔烃完全燃烧的通式：
$$\mathrm{C_nH_{2n-2} + \frac{3n-1}{2}O_2 \xrightarrow{点燃} nCO_2 + (n-1)H_2O}$$

乙炔燃烧现象：火焰很明亮，伴有浓黑烟（含碳量高，燃烧不充分）。乙炔在氧气中燃烧温度可达 $3000^\circ\mathrm{C}$，可用于氧炔焰切割金属。

#### （2）被酸性 $\mathrm{KMnO_4}$ 溶液氧化

炔烃能使酸性 $\mathrm{KMnO_4$ 溶液褪色。

**氧化规律**：
- 端基炔（$\mathrm{R-C \equiv CH}$）：三键端碳被氧化为 $\mathrm{CO_2}$
- 非端基炔：三键碳被氧化为羧基（—COOH）

### 3. 加聚反应

**乙炔的加聚**：
$$\mathrm{nHC \equiv CH \xrightarrow{催化剂} [-CH=CH-]_n}$$

聚乙炔具有导电性，可用于制备导电高分子材料。

### 4. 端基炔的特殊反应（金属炔化物的生成）

端基炔（$\mathrm{R-C \equiv CH}$）具有弱酸性，能与某些金属离子反应生成沉淀：

$$\mathrm{R-C \equiv CH + Ag(NH_3)_2OH \rightarrow R-C \equiv CAg \downarrow + 2NH_3 + H_2O}$$

$$\mathrm{R-C \equiv CH + Cu(NH_3)_2OH \rightarrow R-C \equiv CCu \downarrow + 2NH_3 + H_2O}$$

**注**：
- 端基炔的 H 原子具有一定的活泼性（酸性强于烷烃、烯烃）
- 此反应用于鉴别端基炔
- 金属炔化物干燥时易爆炸，注意安全

## 烷烃、烯烃、炔烃的鉴别

| 试剂 | 烷烃 | 烯烃 | 炔烃 |
| :--- | :---: | :---: | :---: |
| 溴水/溴的 $\mathrm{CCl_4}$ 溶液 | 不褪色 | 褪色（反应较快） | 褪色（反应较慢） |
| 酸性 $\mathrm{KMnO_4}$ 溶液 | 不褪色 | 褪色 | 褪色 |
| $\mathrm{Ag(NH_3)_2OH}$ | 无现象 | 无现象 | 端基炔产生白色沉淀 |

# 芳香烃

## 定义与分类

**芳香烃**：分子里含有一个或多个苯环的烃。

**分类**：
- 苯及其同系物：含一个苯环，苯环上连接烷基
- 稠环芳香烃：两个或多个苯环共用相邻碳原子稠合而成（如萘、蒽）
- 其他芳香烃：苯乙烯等

## 苯

### 组成与结构

**分子式**：$\mathrm{C_6H_6}$

**结构简式**：

**分子结构**：
- 平面正六边形，所有原子处于同一平面上
- 6 个碳原子构成正六边形，键角均为 $120^\circ$

**成键特点**：
- 6 个碳原子均采取 $\mathrm{sp^2}$ 杂化，分别与氢原子及相邻碳原子以 σ 键结合
- 每个碳原子余下的 p 轨道垂直于分子平面，相互平行重叠形成大 π 键（$\Pi_6^6$）
- 6 个碳碳键的键长完全相等（$0.140\ \mathrm{nm}$），介于碳碳单键（$0.154\ \mathrm{nm}$）和碳碳双键（$0.134\ \mathrm{nm}$）之间
- 苯环中不存在单双键交替的结构，而是介于单键和双键之间的特殊共价键

### 物理性质

- 苯是无色、有特殊芳香气味的液体
- 沸点为 $80.1^\circ\mathrm{C}$，易挥发，易燃
- 密度比水小（$0.88\ \mathrm{g/cm^3}$）
- 不溶于水，易溶于有机溶剂
- 苯有毒，是重要的有机溶剂

### 化学性质

苯的化学性质稳定，特征为：**易取代，难加成，能氧化（燃烧）**。

#### 1. 取代反应

苯环上的氢原子在一定条件下可被其他原子或原子团取代。

##### （1）卤代反应

苯与液溴在 $\mathrm{FeBr_3}$（或铁粉）催化下发生取代反应生成溴苯：

溴苯是无色、不溶于水的液体，密度比水大。

**注**：苯与溴水不反应（只能发生萃取），故溴水不能鉴别苯与烷烃；需用液溴与铁粉催化才能发生取代。

##### （2）硝化反应

苯与浓硝酸在浓硫酸催化、加热（$50\sim 60^\circ\mathrm{C}$）条件下发生取代反应生成硝基苯：

硝基苯是无色（因含杂质而呈淡黄色）、有苦杏仁气味、不溶于水、密度大于水的油状液体。

**反应条件控制**：
- 温度过高（$> 60^\circ\mathrm{C}$），苯易挥发，硝酸分解
- 温度过低，反应速率慢
- 采用水浴加热控制温度在 $50\sim 60^\circ\mathrm{C}$

##### （3）磺化反应

苯与浓硫酸在加热条件下发生取代反应生成苯磺酸：

#### 2. 加成反应

苯环具有特殊的稳定性，不易发生加成反应，但在特定条件下可与氢气、氯气等加成。

**催化加氢**：苯与氢气在 Ni 催化、加热条件下加成生成环己烷：

**与氯气加成**：苯在紫外线照射下与氯气发生加成反应生成六氯环己烷（六六六）：

#### 3. 氧化反应

##### （1）燃烧

苯完全燃烧的化学方程式：

苯燃烧现象：火焰明亮，伴有浓黑烟（含碳量极高，燃烧不充分）。

##### （2）与酸性 $\mathrm{KMnO_4}$ 溶液

苯不能使酸性 $\mathrm{KMnO_4}$ 溶液褪色。

## 苯的同系物

**定义**：苯环上的氢原子被烷基取代后生成的化合物。

**通式**：$\mathrm{C_nH_{2n-6}}\ (n \ge 6)$

**结构特点**：苯环与烷基相连，苯环上的氢原子被一个或多个烷基取代。

### 物理性质变化规律

| 性质 | 变化规律 |
| :--- | :--- |
| 状态 | 随碳原子数增多，从液体过渡到固体 |
| 沸点 | 碳原子数增多，沸点升高 |
| 密度 | 均比水小 |
| 水溶性 | 均难溶于水，易溶于有机溶剂 |

### 化学性质

苯的同系物具有苯环的化学性质，同时因侧链的存在，与苯有所不同。

#### 1. 取代反应

##### （1）苯环上的取代

苯环上的氢原子可在一定条件下被取代，取代位置受侧链影响：

- **邻、对位定位基**：烷基是邻、对位定位基，使新进入的取代基主要进入其邻位和对位。
- 例如甲苯硝化时，主要生成邻硝基甲苯和对硝基甲苯。

##### （2）侧链上的取代

在光照条件下，卤素单质取代侧链上的氢原子（与烷烃卤代相似）：

#### 2. 氧化反应

##### （1）燃烧

苯的同系物完全燃烧通式：

##### （2）被酸性 $\mathrm{KMnO_4}$ 溶液氧化

**与苯的区别**：苯不能使酸性 $\mathrm{KMnO_4$ 溶液褪色，但苯的同系物（侧链上与苯环相连的碳原子上有氢原子）能使酸性 $\mathrm{KMnO_4$ 溶液褪色。

**氧化规律**：
- 侧链烃基被氧化为羧基（—COOH），苯环不变
- 无论侧链多长，都被氧化为苯甲酸（$\mathrm{C_6H_5COOH}$）
- 若与苯环直接相连的碳原子上无氢原子，则不能被酸性 $\mathrm{KMnO_4$ 氧化

**说明**：苯环对侧链产生影响，使侧链上的 $\alpha$ -H（与苯环直接相连的碳上的氢）活性增强，易被氧化。

#### 3. 加成反应

与苯类似，苯的同系物在特定条件下可与氢气加成生成环烷烃。

## 稠环芳香烃

两个或多个苯环共用相邻碳原子稠合而成。

**萘**（$\mathrm{C_{10}H_8}$）：由两个苯环共用一对相邻碳原子稠合而成，无色片状晶体，有特殊气味，易升华，是重要的有机化工原料。

**蒽**（$\mathrm{C_{14}H_{10}}$）：由三个苯环稠合而成，无色晶体，可用于合成染料。

## 苯及其同系物的鉴别

| 物质 | 溴水 | 酸性 $\mathrm{KMnO_4}$ 溶液 |
| :--- | :---: | :---: |
| 苯 | 萃取（分层，上层橙红色） | 不褪色 |
| 甲苯（苯的同系物） | 萃取 | 褪色 |
