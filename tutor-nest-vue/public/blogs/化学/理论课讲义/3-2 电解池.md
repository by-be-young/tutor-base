# 电解池基本概念

## 定义与构成条件

**定义**：将电能直接转化为化学能的装置。能量转化：电能→化学能。

**构成条件**：
1. 有外加电源（可能是直接的外加电源，也可能是原电池）。
2. 有导电的两极（电极只要导电即可，对活泼性无要求）。
3. 有电解质环境（内环境可以是电解质溶液，也可以是熔融的电解质或固体电解质）。
4. 形成闭合回路。

## 阴阳极判断

| 阳极 | 阴极 |
| :--- | :--- |
| 物质失电子、发生氧化反应、化合价升高的一极 | 物质得电子、发生还原反应、化合价降低的一极 |
| 外电路中电子流出的一极 | 外电路中电子流入的一极 |
| 内电路中阴离子移向的一极 | 内电路中阳离子移向的一极 |
| 电势高的一极 | 电势低的一极 |

阳、阴极是一对矛盾关系，由于矛盾的对立性，阳、阴极的特征往往相反。为了事半功倍，重点记忆一极的现象即可。矛盾既对立又统一，阴、阳极分别得失的电子总数相同。注意学科之间的联系，充分利用物理学中的电学知识来理解并掌握电化学知识。电极还有“活性”与“惰性”之分，惰性电极一般包括金、铂、石墨、其他特殊材料。

## 放电顺序

**阳极放电顺序（还原剂的还原性由强到弱）**：
金属单质（除 $\mathrm{Pt}$、$\mathrm{Au}$）> $\mathrm{S^{2-}}$ > $\mathrm{SO_3^{2-}}$ > $\mathrm{I^-}$ > $\mathrm{Fe^{2+}}$ > $\mathrm{Br^-}$ > $\mathrm{Cl^-}$ > $\mathrm{OH^-}$ > 最高价含氧酸根离子（如 $\mathrm{SO_4^{2-}}$、$\mathrm{NO_3^-}$、$\mathrm{ClO_4^-}$ 等）

**阴极放电顺序（氧化剂的氧化性由强到弱）**：
$\mathrm{Ag^+}$ > $\mathrm{Fe^{3+}}$ > $\mathrm{Cu^{2+}}$ > $\mathrm{H^+}$（酸）> $\mathrm{Fe^{2+}}$ > $\mathrm{Zn^{2+}}$ > $\mathrm{H^+}$（水）> $\mathrm{Al^{3+}}$、$\mathrm{Mg^{2+}}$、$\mathrm{Na^+}$、$\mathrm{Ca^{2+}}$、$\mathrm{K^+}$

由于溶液的酸碱性、离子浓度的相对大小、电极材料等会影响放电顺序，所以一定要先阅读题干信息，再确定发生反应的物质。

电解水溶液中的 $\mathrm{K^+}$、$\mathrm{Ca^{2+}}$、$\mathrm{Na^+}$、$\mathrm{Mg^{2+}}$、$\mathrm{Al^{3+}}$ 等离子，阴极电极反应等同电解 $\mathrm{H_2O}$：$\mathrm{2H_2O + 2e^- = H_2 \uparrow + 2OH^-}$（放氢生碱）。若用惰性电极电解水溶液中的 $\mathrm{SO_4^{2-}}$、$\mathrm{NO_3^-}$、$\mathrm{ClO_4^-}$ 等最高价含氧酸根离子，阳极电极反应等同电解 $\mathrm{H_2O}$：$\mathrm{2H_2O - 4e^- = O_2 \uparrow + 4H^+}$（放氧生酸）。

$\mathrm{K^+}$、$\mathrm{Ca^{2+}}$、$\mathrm{Na^+}$、$\mathrm{Mg^{2+}}$、$\mathrm{Al^{3+}}$ 在水溶液中无法放电，因为水电离 $\mathrm{H^+}$ 的氧化性更强。欲制备金属 $\mathrm{K}$、$\mathrm{Ca}$、$\mathrm{Na}$、$\mathrm{Mg}$、$\mathrm{Al}$，需要电解其对应物质的熔融态。

## 解决电解池问题的思维建模

1. 先根据外加电源的正、负极，确定电解池的阳、阴极。若阳极为活性电极，必须圈出加以强调。
2. 将电解池中的离子归类并排序（阳离子按氧化性由强到弱排序，阴离子按还原性由强到弱排序）。
3. 根据谁强谁优先以及电极反应式的通式，书写电极反应式。
4. 得失电子守恒的基础上，加和阴、阳极电极反应，即可获得总反应。也可以根据氧化还原反应原理直接推导总反应化学方程式。
5. 完成选择题时，先确定阳极特征，排除定性选项，再根据得失电子守恒进行定量计算。PH 的变化通过“舍小得大”即可判断，两极溶液的差值计算尽量用排除法确定。

## 电极反应式书写步骤

1. 准确判断电解池的阳极、阴极以及各自的反应物，并根据信息、常识、环境推导阳极的氧化产物、阴极的还原产物。一定要考虑环境的后续反应，书写出该环境下的最终产物。
2. 写出阳极、阴极的电极反应通式：
   - 阳极反应通式：还原剂 $-$ $ne^-$ $\rightarrow$ 氧化产物（+其他）
   - 阴极反应通式：氧化剂 $+$ $ne^-$ $\rightarrow$ 还原产物（+其他）
3. 分析还原剂和氧化产物（氧化剂和还原产物）的化合价变化确定失去（得到）的电子数。
4. 调平电荷：根据环境条件或电解质种类，选择正确离子完成电荷守恒。例如酸性水溶液用 $\mathrm{H^+}$、碱性水溶液用 $\mathrm{OH^-}$、熔融碳酸盐用 $\mathrm{CO_3^{2-}}$、熔融氧化物用 $\mathrm{O^{2-}}$ 等。
5. 元素守恒：若电解质为水溶液，可利用“看氢补水、用氧检查”完成 $\mathrm{H}$、$\mathrm{O}$ 元素守恒。
6. 书写总反应：调整电极反应式系数，使阴、阳极的得、失电子数相等，将阳、阴极电极反应式加和得到总反应。

# 电解原理的应用

## 氯碱工业

电解饱和食盐水获得 $\mathrm{Cl_2}$、$\mathrm{NaOH}$、$\mathrm{H_2}$ 的工艺。

阳离子交换膜电解槽：
- 阳极（惰性电极）：$\mathrm{2Cl^- - 2e^- = Cl_2 \uparrow}$（氧化反应）
- 阴极（碳钢网）：$\mathrm{2H_2O + 2e^- = H_2 \uparrow + 2OH^-}$（还原反应）
- 总反应化学方程式：$\mathrm{2NaCl + 2H_2O \xlongequal{电解} Cl_2 \uparrow + H_2 \uparrow + 2NaOH}$
- 总反应离子方程式：$\mathrm{2Cl^- + 2H_2O \xlongequal{电解} Cl_2 \uparrow + H_2 \uparrow + 2OH^-}$

阳离子交换膜的作用：只允许 $\mathrm{Na^+}$ 等阳离子通过，不允许 $\mathrm{Cl^-}$、$\mathrm{OH^-}$ 等阴离子及气体分子通过，可以防止阴极产生的 $\mathrm{H_2}$ 与阳极产生的 $\mathrm{Cl_2}$ 混合发生爆炸，也能避免 $\mathrm{Cl_2}$ 与阴极产生的 $\mathrm{NaOH}$ 溶液反应而影响 $\mathrm{NaOH}$ 溶液的产量。

## 电渗析法淡化海水

目的：获得淡水、浓缩海水、氯气、氢气、氢氧化钠。

装置：电解槽中阴离子交换膜和阳离子交换膜交替排列，将电解槽分隔成多个独立的间隔室。

工作原理：电极 2 产生 $\mathrm{H_2}$，电极反应式为 $\mathrm{2H_2O + 2e^- = H_2 \uparrow + 2OH^-}$，发生还原反应，故电极 2 是阴极，电极 1 为阳极，其电极反应式为 $\mathrm{2Cl^- - 2e^- = Cl_2 \uparrow}$。

## 电镀与粗铜精炼

|  | 电镀 | 电解精炼铜 |
| :--- | :--- | :--- |
| 阳极材料 | 镀层金属 $\mathrm{Cu}$ | 粗铜（含 $\mathrm{Zn}$、$\mathrm{Fe}$、$\mathrm{Ni}$、$\mathrm{Ag}$、$\mathrm{Au}$ 等） |
| 阴极材料 | 镀件金属 $\mathrm{Fe}$ | 纯铜 |
| 电解质溶液 | 硫酸铜溶液 | 硫酸铜溶液 |
| 阳极反应 | $\mathrm{Cu - 2e^- = Cu^{2+}}$ | 前期：$\mathrm{Zn - 2e^- = Zn^{2+}}$、$\mathrm{Fe - 2e^- = Fe^{2+}}$、$\mathrm{Ni - 2e^- = Ni^{2+}}$；后期：$\mathrm{Cu - 2e^- = Cu^{2+}}$ |
| 阴极反应 | $\mathrm{Cu^{2+} + 2e^- = Cu}$ | $\mathrm{Cu^{2+} + 2e^- = Cu}$ |
| 溶液变化 | $\mathrm{Cu^{2+}}$ 浓度保持不变 | $\mathrm{Cu^{2+}}$ 浓度减小 |
| 两极质量 | 阳极减少质量 $=$ 阴极增加质量 | 阳极减少质量 $\neq$ 阴极增加质量 |

## 金属的冶炼

|  | 总反应化学方程式 | 电极反应式 |
| :--- | :--- | :--- |
| 冶炼钠 | $\mathrm{2NaCl(熔融) \xlongequal{电解} 2Na + Cl_2 \uparrow}$ | 阳极：$\mathrm{2Cl^- - 2e^- = Cl_2 \uparrow}$；阴极：$\mathrm{Na^+ + e^- = Na}$ |
| 冶炼镁 | $\mathrm{MgCl_2(熔融) \xlongequal{电解} Mg + Cl_2 \uparrow}$ | 阳极：$\mathrm{2Cl^- - 2e^- = Cl_2 \uparrow}$；阴极：$\mathrm{Mg^{2+} + 2e^- = Mg}$ |
| 冶炼铝 | $\mathrm{2Al_2O_3(熔融) \xlongequal{电解} 4Al + 3O_2 \uparrow}$ | 阳极：$\mathrm{2O^{2-} - 4e^- = O_2 \uparrow}$；阴极：$\mathrm{Al^{3+} + 3e^- = Al}$ |

## 二次电池的充电

二次电池的充电过程，就是让原电池的活性物质复原的过程。放电时负极发生氧化反应，充电时二次电池的负极需与外加电源的负极相连，作为阴极发生还原反应。同理，放电时正极发生还原反应，充电时二次电池的正极需与外加电源的正极相连，作为阳极发生氧化反应。

## 金属防腐

为了不让金属单质失去电子，可以将金属单质和外加电源的负极相连作为阴极。在此情况下，阴极的金属不仅无法失去电子，反而被电源负极输送的电子保护起来，这种保护金属的方法称为“外加电流法”。

# 高频考查的电解池题型

## 溶液质量变化量的计算

多室电解池中，电极反应和离子在电场作用下的定向移动分别构成了电解池的外电路和内电路。离子交换膜的类型决定了哪些离子可以在相邻隔室之间迁移，也决定了各隔室溶液浓度的变化。在计算某一隔室溶液质量变化时，既要考虑电极反应中进入或离开该隔室的气体、析出的固体，也要考虑通过离子交换膜迁入或迁出的离子，这两部分质量变化的代数和即为该室溶液质量的净变化。

## 溶液 $\mathrm{pH}$ 变化问题

电解过程中，溶液 $\mathrm{pH}$ 的变化由 $\mathrm{H^+}$ 或 $\mathrm{OH^-}$ 的浓度变化决定。对于电极周围的局部溶液，只需考虑该电极上发生的反应本身引起的 $\mathrm{H^+}$ 或 $\mathrm{OH^-}$ 浓度变化，离子交换膜对 $\mathrm{H^+}$ 或 $\mathrm{OH^-}$ 的迁移也会改变局部的 $\mathrm{pH}$。若整个电解池的 $\mathrm{pH}$ 变化，则需要综合阳极和阴极反应以及膜的透过情况进行分析。

## 电解池溶液复原问题

电解池工作时，溶液中的离子在电极上发生氧化还原反应，以固体或气体的形式离开溶液，导致溶液中溶质或溶剂的量发生变化。要使电解后的溶液恢复至原来的浓度，需要向溶液中加入一定量的“损失组分”，通常是与阴、阳极产物组合形成的化合物。需要强调的是，加水只能恢复溶剂水的损失，若电解质本身也发生了消耗，则还需要加入相应的溶质才能复原。

## 多离子交换膜的电解池装置

多离子交换膜的电解池中，通常将电解槽分隔成三个或更多的隔室，每个隔室承担不同的功能。解决问题的关键在于理解每种离子交换膜的选择透过性：阳离子交换膜只允许阳离子通过，阴离子交换膜只允许阴离子通过。根据离子的移动方向和数量，可以确定各隔室产物的种类和浓度变化。双极膜在电场作用下将水解离为 $\mathrm{H^+}$ 和 $\mathrm{OH^-}$，相当于一个持续的 $\mathrm{H^+}$ 和 $\mathrm{OH^-}$ 供应源。

## 有机化学与电化学综合题型

有机物的化合价处理方法：若有机物只有一个碳周围的化学键发生变化，则直接分析该碳的真实化合价；若有机物很多碳周围的化学键发生变化，则用分子式分析碳的平均化合价；若有机物只有氢原子或者氧原子的变化，直接分析组成即可得化合价变化，得氧或失氢化合价升高，得氢或失氧化合价降低，每个氧对应变 $2$ 价，每个氢对应变 $1$ 价；若有机物组成上只有 $\mathrm{Na^+}$ 或 $\mathrm{K^+}$ 个数的变化，则 $\mathrm{Na^+}$ 或 $\mathrm{K^+}$ 减少的个数即负极或阳极失电子的个数，$\mathrm{Na^+}$ 或 $\mathrm{K^+}$ 增加的个数即正极或阴极得电子的个数。

## 原电池与电解池综合

当多个容器相连且无外加电源时，需先判断是否存在自发的氧化还原反应以确定原电池装置，其余则为电解池装置。串联电路中各电极得失电子数相同，且转移电子数等于通过每张离子交换膜的电荷数。原电池与电解池综合问题的突破口通常是：先根据自发反应确定原电池的正负极，再根据电源连接关系确定电解池的阴阳极，最后利用得失电子守恒将两个装置关联起来。
