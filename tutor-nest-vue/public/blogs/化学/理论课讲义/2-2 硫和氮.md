# 硫单质、硫的氧化物

## 硫元素

硫的最低化合价为 $-2$、最高化合价为 $+6$，常见化合价：$-2$、$0$、$+4$、$+6$；稳价为 $0$ 价、$+6$ 价，$+6$ 价比 $0$ 价更稳定。

若溶液中反应物 S 元素化合价为负数，其氧化产物几乎都是 S 单质；若溶液中反应物 S 元素的化合价为 $+4$ 价，其氧化产物几乎都是 $\mathrm{SO_4^{2-}}$。

硫在自然界中既有游离态（火山口附近或地壳的岩层中），又有化合态，如黄铁矿（$\mathrm{FeS_2}$）、黄铜矿（$\mathrm{CuFeS_2}$）、石膏（$\mathrm{CaSO_4 \cdot 2H_2O}$）、芒硝（$\mathrm{Na_2SO_4 \cdot 10H_2O}$）等。

## 硫单质

**物理性质**：常温下，S 是一种黄色晶体，质脆。难溶于水，微溶于酒精，易溶于 $\mathrm{CS_2}$。硫有多种同素异形体，没有特殊说明，默认的是 $\mathrm{S_8}$（正交硫）；在化学方程式中均用“S”表示固体硫单质的化学式。

**化学性质**：0 价是硫元素的中间价，所以硫单质既有氧化性，又有还原性。由于 0 价比较稳定，因此 S 单质也比较稳定，但在一定条件下也能与金属单质、某些非金属单质或化合物反应。

与金属单质的反应：
- $\mathrm{Fe + S \xlongequal{\triangle} FeS}$（生成黑色固体）
- $\mathrm{2Cu + S \xlongequal{\triangle} Cu_2S}$（生成黑色固体）

S 的氧化性较弱，与变价金属反应只能生成低价金属硫化物。但汞比较特殊，洒落的水银用硫粉即可转化成 $\mathrm{HgS}$：$\mathrm{Hg + S = HgS}$。

与非金属单质的反应：
- $\mathrm{H_2 + S \xlongequal{\triangle} H_2S}$
- $\mathrm{O_2 + S \xlongequal{点燃} SO_2}$

S 在 $\mathrm{O_2}$ 中燃烧，无论 $\mathrm{O_2}$ 多少，只能生成 $\mathrm{SO_2}$。$\mathrm{SO_2}$ 转化为 $\mathrm{SO_3}$ 需要催化剂，如 $\mathrm{V_2O_5}$。

与浓硝酸反应：$\mathrm{S + 6HNO_3(浓) \xlongequal{\triangle} H_2SO_4 + 6NO_2 \uparrow + 2H_2O}$

与碱的反应：$\mathrm{3S + 6NaOH(浓) \xlongequal{\triangle} 2Na_2S + Na_2SO_3 + 3H_2O}$（可用热的烧碱溶液洗去试管上的硫黄）

**用途**：制硫酸、制火药、制作药皂等。

## 二氧化硫

**物理性质**：无色有刺激性气味的有毒气体，在通常情况下，1 体积的水可溶解约 40 体积的 $\mathrm{SO_2}$，密度比空气的大。

**化学性质**：

酸性氧化物通性：
- $\mathrm{SO_2(少) + 2NaOH = Na_2SO_3 + H_2O}$
- $\mathrm{SO_2(足) + NaOH = NaHSO_3}$
- $\mathrm{SO_2(少) + Ca(OH)_2 = CaSO_3 \downarrow + H_2O}$
- $\mathrm{2SO_2(足) + Ca(OH)_2 = Ca(HSO_3)_2}$（可溶）
- $\mathrm{SO_2 + H_2O = H_2SO_3}$

强还原性（能与多种氧化剂反应）：
- $\mathrm{SO_2 + X_2 + 2H_2O = SO_4^{2-} + 2X^- + 4H^+}$（$\mathrm{X_2 = Cl_2、Br_2、I_2}$）
- $\mathrm{SO_2 + 2Fe^{3+} + 2H_2O = SO_4^{2-} + 2Fe^{2+} + 4H^+}$
- $\mathrm{SO_2 + H_2O_2 = SO_4^{2-} + 2H^+}$
- $\mathrm{2SO_2 + O_2 \xrightleftharpoons[催化剂]{\triangle} 2SO_3}$
- $\mathrm{3SO_2 + 2NO_3^- + 2H_2O = 3SO_4^{2-} + 2NO + 4H^+}$
- $\mathrm{3SO_2 + Cr_2O_7^{2-} + 2H^+ = 3SO_4^{2-} + 2Cr^{3+} + H_2O}$
- $\mathrm{5SO_2 + 2MnO_4^- + 2H_2O = 5SO_4^{2-} + 2Mn^{2+} + 4H^+}$

弱氧化性：$\mathrm{SO_2 + 2H_2S = 3S \downarrow + 2H_2O}$

特性：暂时漂白品红以及自然界的有机色素。

$\mathrm{SO_2}$ 是 $\mathrm{H_2SO_3}$ 的酸酐，$\mathrm{H_2SO_3}$ 是二元弱酸，所以 $\mathrm{SO_2}$ 与碱的反应存在量变引起质变。

能使澄清石灰水先变浑浊，再变澄清的气体除了 $\mathrm{CO_2}$ 之外，还有 $\mathrm{SO_2}$。

气体 $\mathrm{SO_2}$ 和 $\mathrm{O_2}$ 不容易反应，需要催化剂和加热条件；但是水溶液中的 $\mathrm{SO_2}$ 很容易和 $\mathrm{O_2}$ 反应：$\mathrm{2SO_2 + O_2 + 2H_2O = 2H_2SO_4}$。

在水溶液中，$\mathrm{SO_2}$ 的氧化产物一般为 $\mathrm{SO_4^{2-}}$。$\mathrm{SO_2}$ 参加的氧化还原反应的离子方程式绝大多数需要前面补 $\mathrm{H_2O}$，后面补 $\mathrm{H^+}$。这就导致 $\mathrm{SO_2}$ 参加反应后，环境的酸性往往会增强，pH 减小。

**漂白性**：
- $\mathrm{SO_2}$ 和 $\mathrm{Cl_2}$ 通入品红溶液均能使溶液褪色，通入 $\mathrm{SO_2}$ 后褪色的品红溶液加热后红色可以恢复，说明 $\mathrm{SO_2}$ 的漂白作用是暂时的；但通入 $\mathrm{Cl_2}$ 后褪色的品红溶液加热后红色无法复原。
- $\mathrm{SO_2}$ 不能漂白酸碱指示剂，因此将 $\mathrm{SO_2}$ 通入紫色石蕊溶液中，溶液只变红不褪色。
- 将 $\mathrm{SO_2}$ 通入含酚酞的 NaOH 溶液中，溶液红色褪去，这与 $\mathrm{SO_2}$ 漂白性无关，而是体现 $\mathrm{SO_2}$ 酸性氧化物的通性。
- $\mathrm{SO_2}$ 使酸性 $\mathrm{KMnO_4}$ 溶液褪色，或使溴水褪色，都是体现 $\mathrm{SO_2}$ 的还原性而非漂白性。

$\mathrm{SO_2}$ 通入 $\mathrm{BaCl_2}$ 溶液（或 $\mathrm{CaCl_2}$ 溶液）没有明显现象，根本原因是 $\mathrm{BaSO_3}$（或 $\mathrm{CaSO_3}$）溶于酸溶液。

**制备**：
- 强酸制弱酸：$\mathrm{Na_2SO_3}$ (s) ${+ H_2SO_4}$ (70%) ${= Na_2SO_4 + SO_2 \uparrow + H_2O}$
- 氧化还原反应：$\mathrm{Cu + 2H_2SO_4(浓) \xlongequal{\triangle} CuSO_4 + SO_2 \uparrow + 2H_2O}$

**用途**：漂白织物或纸张；食品的防腐；制备硫酸等。$\mathrm{SO_2}$ 虽有毒，但是可以在食品中添加适量 $\mathrm{SO_2}$ 进行防腐。如葡萄酒添加适量的 $\mathrm{SO_2}$ 可以起到杀菌和抗氧化的作用。

## 三氧化硫

标准状况下 $\mathrm{SO_3}$ 为固体，与水互溶。

具有酸性氧化物的通性：
- $\mathrm{SO_3 + 2NaOH = Na_2SO_4 + H_2O}$
- $\mathrm{SO_3 + CaO = CaSO_4}$
- $\mathrm{SO_3 + H_2O = H_2SO_4}$

## 酸雨

定义：pH < 5.6 的雨水（$\mathrm{CO_2}$ 饱和溶液 pH 为 5.6，所以 $\mathrm{CO_2}$ 不是引起酸雨的因素）。

产生酸雨的人为因素：燃烧化石能源释放的 $\mathrm{SO_2}$ 形成硫酸型酸雨；汽车尾气中的 $\mathrm{NO_x}$ 形成硝酸型酸雨。

危害：使土壤酸化；农作物减产；损坏建筑物；增加呼吸道疾病的发病率等。

消除方法：开发新能源；使用燃煤脱硫技术；工业废气处理后再排放等。

**煤的脱硫方法——石灰法**：向燃烧的煤中添加石灰石或生石灰，将煤炭中的硫元素转化为 $\mathrm{CaSO_4}$。涉及反应：$\mathrm{CaCO_3 \xlongequal{高温} CaO + CO_2 \uparrow}$、$\mathrm{2CaO + 2SO_2 + O_2 \xlongequal{\triangle} 2CaSO_4}$。

# 含硫的酸、盐及其他含硫化合物

## 氢硫酸（$\mathrm{H_2S}$）

**物理性质**：常温下，$\mathrm{H_2S}$ 是具有臭鸡蛋气味的剧毒气体，可溶于水，密度比空气略大。$\mathrm{H_2S}$ 的水溶液称为氢硫酸，氢硫酸是二元弱酸。

**化学性质**：

二元弱酸性：
- 少量 $\mathrm{H_2S}$ 通入 NaOH 溶液：$\mathrm{H_2S + 2NaOH = Na_2S + 2H_2O}$（离子方程式：$\mathrm{H_2S + 2OH^- = S^{2-} + 2H_2O}$）
- 过量 $\mathrm{H_2S}$ 通入 NaOH 溶液：$\mathrm{H_2S + NaOH = NaHS + H_2O}$（离子方程式：$\mathrm{H_2S + OH^- = HS^- + H_2O}$）
- $\mathrm{H_2S}$ 通入 $\mathrm{Na_2S}$ 溶液：$\mathrm{H_2S + Na_2S = 2NaHS}$（离子方程式：$\mathrm{H_2S + S^{2-} = 2HS^-}$）

沉淀反应：$\mathrm{H_2S + CuSO_4 = CuS \downarrow + H_2SO_4}$（离子方程式：$\mathrm{H_2S + Cu^{2+} = CuS \downarrow + 2H^+}$）。该反应违背“强酸制弱酸”的原理，但遵循“溶解度大制溶解度小”的原理。$\mathrm{H_2S}$ 通入 $\mathrm{FeSO_4}$ 溶液无明显现象，因为 $\mathrm{FeS}$ 可溶于 $\mathrm{H_2SO_4}$。

强还原性（氧化产物一般为 S，若氧化剂极强可氧化成 $\mathrm{SO_4^{2-}}$）：
- $\mathrm{2H_2S + SO_2 = 3S \downarrow + 2H_2O}$
- $\mathrm{H_2S + X_2 = S \downarrow + 2HX}$（$\mathrm{X_2 = Cl_2、Br_2、I_2}$）
- $\mathrm{2H_2S(aq) + O_2 = 2S \downarrow + 2H_2O}$
- $\mathrm{H_2S + 2Fe^{3+} = S \downarrow + 2Fe^{2+} + 2H^+}$
- $\mathrm{H_2S + H_2O_2 = S \downarrow + 2H_2O}$
- $\mathrm{H_2S(少) + H_2SO_4(浓) = S \downarrow + SO_2 + 2H_2O}$

浓硫酸可以氧化 $\mathrm{H_2S}$，所以不能用浓硫酸干燥 $\mathrm{H_2S}$ 气体。

**制备**：$\mathrm{FeS + H_2SO_4 = H_2S \uparrow + FeSO_4}$（稀硫酸不能用稀硝酸或浓硫酸代替，因为稀硝酸、浓硫酸均具有强氧化性，会将 $\mathrm{H_2S}$ 氧化）。

## 亚硫酸（$\mathrm{H_2SO_3}$）

**化学性质**：

二元弱酸性：
- $\mathrm{H_2SO_3 + 2NaOH = Na_2SO_3 + 2H_2O}$（离子方程式：$\mathrm{H_2SO_3 + 2OH^- = SO_3^{2-} + 2H_2O}$）
- $\mathrm{H_2SO_3 + NaOH = NaHSO_3 + H_2O}$（离子方程式：$\mathrm{H_2SO_3 + OH^- = HSO_3^- + H_2O}$）
- $\mathrm{H_2SO_3 + Na_2SO_3 = 2NaHSO_3}$（离子方程式：$\mathrm{H_2SO_3 + SO_3^{2-} = 2HSO_3^-}$）

强还原性：氧化产物在水溶液中一般为 $\mathrm{SO_4^{2-}}$。

受热不稳定：$\mathrm{H_2SO_3 \xlongequal{\triangle} SO_2 \uparrow + H_2O}$

## 硫酸（$\mathrm{H_2SO_4}$）

**浓硫酸的物理性质**：常温下，浓硫酸是黏稠的油状液体，密度大于水，硫酸与水互溶，稀释浓硫酸时放出大量热；具有吸水性；具有较高的沸点，难挥发。

**浓硫酸的化学性质**：

酸的通性：$\mathrm{H_2SO_4 + Ba(OH)_2 = BaSO_4 \downarrow + 2H_2O}$

脱水性：$\mathrm{C_{12}H_{22}O_{11}(蔗糖) \xrightarrow{浓硫酸} 12C + 11H_2O}$

强氧化性：
- 与金属单质：$\mathrm{Cu + 2H_2SO_4(浓) \xlongequal{\triangle} CuSO_4 + SO_2 \uparrow + 2H_2O}$；$\mathrm{Zn + 2H_2SO_4(浓) \xlongequal{\triangle} ZnSO_4 + SO_2 \uparrow + 2H_2O}$
- 与非金属单质：$\mathrm{C + 2H_2SO_4(浓) \xlongequal{\triangle} CO_2 \uparrow + 2SO_2 \uparrow + 2H_2O}$
- 与某些化合物：$\mathrm{2HI + H_2SO_4(浓) = I_2 + SO_2 \uparrow + 2H_2O}$

常温下，铁、铝遇浓硫酸、浓硝酸会发生钝化。

浓硫酸与金属单质反应属于部分氧化还原反应，浓硫酸既体现酸性又体现强氧化性。在浓硫酸与 Cu 的反应中，体现酸性的硫酸与体现氧化性的硫酸的物质的量之比为 1:1。浓硫酸与非金属单质反应中，浓硫酸只体现强氧化性。

**硫酸的工业制备流程**：
- $\mathrm{S + O_2 \xlongequal{点燃} SO_2}$ 或 $\mathrm{4FeS_2 + 11O_2 \xlongequal{高温} 2Fe_2O_3 + 8SO_2}$
- $\mathrm{2SO_2 + O_2 \xrightleftharpoons[催化剂]{\triangle} 2SO_3}$
- $\mathrm{SO_3 + H_2O = H_2SO_4}$

## 硫化物

常考硫化物的溶解度：$\mathrm{K_2S}$、$\mathrm{Na_2S}$、$\mathrm{(NH_4)_2S}$ 易溶于水；$\mathrm{Al_2S_3}$ 在水中彻底双水解；$\mathrm{FeS}$、$\mathrm{ZnS}$ 难溶于水，易溶于酸；$\mathrm{CuS}$、$\mathrm{Ag_2S}$ 既难溶于水，又难溶于酸。

$\mathrm{S^{2-}}$ 水解后溶液呈碱性，可以和酸反应：
- $\mathrm{Na_2S + HCl(少) = NaHS + NaCl}$
- $\mathrm{Na_2S + 2HCl(足) = H_2S \uparrow + 2NaCl}$
- $\mathrm{Na_2S + H_2S = 2NaHS}$

$\mathrm{S^{2-}}$ 有很强的还原性：$\mathrm{S^{2-} + 2Fe^{3+} = S \downarrow + 2Fe^{2+}}$

## 亚硫酸盐

大多数亚硫酸盐难溶于水，但易溶于盐酸。

$\mathrm{SO_3^{2-}}$ 水解后溶液呈碱性，可以和酸反应：
- $\mathrm{Na_2SO_3 + HCl(少) = NaHSO_3 + NaCl}$
- $\mathrm{Na_2SO_3 + 2HCl(足) = SO_2 \uparrow + 2NaCl + H_2O}$
- $\mathrm{Na_2SO_3 + SO_2 + H_2O = 2NaHSO_3}$

$\mathrm{SO_3^{2-}}$ 有较强的还原性，氧化产物一般为 $\mathrm{SO_4^{2-}}$：
- $\mathrm{SO_3^{2-} + Cl_2 + H_2O = SO_4^{2-} + 2Cl^- + 2H^+}$
- $\mathrm{3SO_3^{2-} + Cl_2 + H_2O = SO_4^{2-} + 2Cl^- + 2HSO_3^-}$

## 亚硫酸氢盐

$\mathrm{HSO_3^-}$ 既能水解又能电离，具有两性：
- $\mathrm{NaHSO_3 + HCl = SO_2 \uparrow + NaCl + H_2O}$
- $\mathrm{NaHSO_3 + NaOH = Na_2SO_3 + H_2O}$

$\mathrm{HSO_3^-}$ 有较强的还原性，氧化产物一般为 $\mathrm{SO_4^{2-}}$。

## 硫酸盐

$\mathrm{SO_4^{2-}}$ 的化合价非常稳定，难以发生氧化还原反应。

$\mathrm{SO_4^{2-}}$ 的检验：取少量待测液于试管中，先加入盐酸酸化，无明显现象，再滴加几滴 $\mathrm{BaCl_2}$ 溶液，若生成白色沉淀，则说明待测液中有 $\mathrm{SO_4^{2-}}$。

## 硫酸氢盐

$\mathrm{NaHSO_4}$ 为离子化合物，在熔融状态下电离出 $\mathrm{Na^+}$、$\mathrm{HSO_4^-}$；在水溶液中完全电离为 $\mathrm{Na^+}$、$\mathrm{H^+}$、$\mathrm{SO_4^{2-}}$。

$\mathrm{NaHSO_4}$ 与 $\mathrm{Ba(OH)_2}$ 反应：
- $n(\mathrm{NaHSO_4}):n(\mathrm{Ba(OH)_2}) = 1:1$：$\mathrm{H^+ + SO_4^{2-} + Ba^{2+} + OH^- = BaSO_4 \downarrow + H_2O}$
- $n(\mathrm{NaHSO_4}):n(\mathrm{Ba(OH)_2}) = 2:1$：$\mathrm{2H^+ + SO_4^{2-} + Ba^{2+} + 2OH^- = BaSO_4 \downarrow + 2H_2O}$

## 硫代硫酸盐

$\mathrm{S_2O_3^{2-}}$ 可看作是 $\mathrm{SO_4^{2-}}$ 的一个 O 原子被 S 原子替代的产物。$\mathrm{Na_2S_2O_3}$ 能稳定存在于碱性环境中，在酸性环境中会转化成 S、$\mathrm{SO_2}$：
$\mathrm{S_2O_3^{2-} + 2H^+ = S \downarrow + SO_2 \uparrow + H_2O}$

# 氮气与氮的氧化物

## 氮元素与氮气

氮元素在自然界中的存在形态既有游离态，又有化合态。游离态是大气中的氮气，化合态主要存在于动植物的蛋白质以及海水、土壤里的硝酸盐、铵盐中。氮元素的最低化合价为 $-3$、最高化合价为 $+5$，常见的化合价有 $-3$、$0$、$+2$、$+3$、$+4$、$+5$，稳价为 $0$ 价。

氮气的电子式是 $\mathrm{:N \equiv N:}$，结构式为 $\mathrm{N \equiv N}$，氮氮三键键能大，所以氮气的化学性质很稳定。与氮气互为等电子体粒子有 $\mathrm{CO}$、$\mathrm{CN^-}$、$\mathrm{C_2^{2-}}$。

### 化学性质

0 价是氮元素的稳价和中间价，所以氮气具有较弱氧化性和还原性。

与金属反应：$\mathrm{3Mg + N_2 \xlongequal{点燃} Mg_3N_2}$

与非金属反应：
- 与氢气反应：$\mathrm{3H_2 + N_2 \xrightleftharpoons[高温、高压]{催化剂} 2NH_3}$
- 与氧气反应：$\mathrm{N_2 + O_2 \xlongequal{放电或高温} 2NO}$

$\mathrm{N_2}$ 与 $\mathrm{O_2}$ 在高温或放电条件下发生反应，不管 $\mathrm{O_2}$ 多或少，只能生成 $\mathrm{NO}$。

**用途**：人工合成氨、作保护气等。

### 氮的固定

将大气中游离的氮（即 $\mathrm{N_2}$）转化为氮的化合物的过程。分类：①高能固氮（雷雨天气，氧气和氮气放电时生成 $\mathrm{NO}$）；②生物固氮（豆科植物的根瘤菌将氮气转化成含氮化合物）；③人工固氮（人工合成氨）。

## 氮的氧化物

| 氮的氧化物 | $\mathrm{N_2O}$ | $\mathrm{NO}$ | $\mathrm{N_2O_3}$ | $\mathrm{NO_2}$ | $\mathrm{N_2O_4}$ | $\mathrm{N_2O_5}$ |
| :--- | :--- | :--- | :--- | :--- | :--- | :--- |
| N 的化合价 | $+1$ | $+2$ | $+3$ | $+4$ | $+4$ | $+5$ |
| 是否为酸性氧化物 | 否 | 否 | 是 | 否 | 否 | 是 |
| 对应的酸 | 无 | 无 | $\mathrm{HNO_2}$ | 无 | 无 | $\mathrm{HNO_3}$ |

### NO 的性质

物理性质：常温下，NO 为无色无味的有毒气体，难溶于水，密度与空气相近。

化学性质：
- $\mathrm{2NO + O_2 = 2NO_2}$
- $\mathrm{NO + NO_2 + 2NaOH = 2NaNO_2 + H_2O}$
- $\mathrm{4NO + 3O_2 + 4NaOH = 4NaNO_3 + 2H_2O}$
- $\mathrm{2NO + 2CO \xrightleftharpoons[催化剂]{\triangle} N_2 + 2CO_2}$

实验室制备：$\mathrm{3Cu + 8HNO_3(稀) = 3Cu(NO_3)_2 + 2NO \uparrow + 4H_2O}$

NO 易与 $\mathrm{O_2}$ 反应且密度与空气相近，不能用排空气法收集，主要用排水法收集。

### NO 2 的性质

物理性质：常温下，$\mathrm{NO_2}$ 为红棕色有刺激性气味的有毒气体，易溶于水，密度大于空气。

化学性质：
- $\mathrm{3NO_2 + H_2O = NO + 2HNO_3}$
- $\mathrm{2NO_2 + 2NaOH = NaNO_3 + NaNO_2 + H_2O}$
- $\mathrm{4NO_2 + O_2 + 4NaOH = 4NaNO_3 + 2H_2O}$
- $\mathrm{NO_2 + NO + 2NaOH = 2NaNO_2 + H_2O}$
- $\mathrm{2NO_2 + 4CO \xrightleftharpoons[催化剂]{\triangle} N_2 + 4CO_2}$
- $\mathrm{2NO_2(g) \rightleftharpoons N_2O_4(g) \quad \Delta H = -56.9\ \mathrm{kJ/mol}}$

实验室制备：$\mathrm{Cu + 4HNO_3(浓) = Cu(NO_3)_2 + 2NO_2 \uparrow + 2H_2O}$

### NOx 的危害

光化学烟雾、硝酸型酸雨、臭氧空洞、使人中毒。

# 氨与铵盐

## 氨

### 分子结构

电子式：$\mathrm{H{:}N{:}H}$（N 有孤电子对）

### 物理性质

常温下，氨是无色有强烈刺激性气味的气体，密度小于空气，极易溶于水（在常温常压下，1 体积水大约可溶解 700 体积氨）。氨存在分子间氢键，易液化，液氨汽化时要吸收大量的热，使周围温度急剧降低，因此液氨可用作制冷剂。

### 化学性质

**碱性**：
- $\mathrm{NH_3 + H_2O \rightleftharpoons NH_3 \cdot H_2O \rightleftharpoons NH_4^+ + OH^-}$
- $\mathrm{NH_3 + HCl = NH_4Cl}$

**强还原性**：
- $\mathrm{8NH_3(足) + 3Cl_2 = N_2 + 6NH_4Cl}$
- $\mathrm{4NH_3 + 3O_2(不足) \xlongequal{点燃} 2N_2 + 6H_2O}$
- $\mathrm{8NH_3 + 6NO_2 \xlongequal{点燃} 12H_2O + 7N_2}$
- $\mathrm{4NH_3 + 5O_2 \xrightleftharpoons[催化剂]{\triangle} 4NO + 6H_2O}$（工业制硝酸最关键的一步）

**配位反应**：
- $\mathrm{AgCl + 2NH_3 = [Ag(NH_3)_2]^+ + Cl^-}$
- $\mathrm{AgOH + 2NH_3 = [Ag(NH_3)_2]^+ + OH^-}$
- $\mathrm{Cu(OH)_2 + 4NH_3 = [Cu(NH_3)_4]^{2+} + 2OH^-}$

### 实验室制备

- $\mathrm{2NH_4Cl + Ca(OH)_2 \xlongequal{\triangle} CaCl_2 + 2NH_3 \uparrow + 2H_2O}$
- 将浓氨水滴入碱石灰中

干燥：常用碱石灰干燥氨。

收集：向下排空气法或排液（$\mathrm{CCl_4}$）法。

尾气处理：用水或酸吸收，注意防倒吸。

### 喷泉实验

使烧瓶内外产生较大的压强差（容器内压强远低于大气压），利用大气压将烧杯中的液体压入烧瓶内。常见组合：$\mathrm{NH_3}$ 和 $\mathrm{HCl}$ 用水作引发剂；$\mathrm{CO_2}$、$\mathrm{SO_2}$、$\mathrm{H_2S}$、$\mathrm{Cl_2}$、$\mathrm{NO_2}$ 用 NaOH 溶液作引发剂。

## 联氨（肼，$\mathrm{N_2H_4}$）

物理性质：常温下，肼为具有刺激性气味的无色液体，可与水形成氢键，与水互溶。

化学性质：
- 碱性：$\mathrm{N_2H_4 + H_2O \rightleftharpoons N_2H_5^+ + OH^-}$
- 还原性：$\mathrm{N_2H_4 + O_2 \xlongequal{点燃} N_2 + 2H_2O}$（高效燃料）

## 一水合氨（$\mathrm{NH_3 \cdot H_2O}$）

$\mathrm{NH_3 \cdot H_2O}$ 是一元弱碱，其电离平衡常数与醋酸相当，浓溶液易挥发。

化学性质：
- $\mathrm{NH_3 \cdot H_2O + HCl = NH_4Cl + H_2O}$
- $\mathrm{CuSO_4 + 2NH_3 \cdot H_2O = Cu(OH)_2 \downarrow + (NH_4)_2SO_4}$
- $\mathrm{NH_3 \cdot H_2O \xlongequal{\triangle} NH_3 \uparrow + H_2O}$

## 铵盐

物理性质：绝大多数的铵盐易溶于水，且溶于水时会吸收大量的热。

化学性质：
- 水解后呈酸性，能与强碱反应：$\mathrm{NH_4Cl + NaOH = NaCl + NH_3 \cdot H_2O}$
- 受热易分解：
  - $\mathrm{NH_4Cl \xlongequal{\triangle} NH_3 \uparrow + HCl \uparrow}$
  - $\mathrm{NH_4HCO_3 \xlongequal{\triangle} NH_3 \uparrow + CO_2 \uparrow + H_2O}$
  - $\mathrm{5NH_4NO_3 \xlongequal{\triangle} 4N_2 \uparrow + 2HNO_3 + 9H_2O}$

$\mathrm{NH_4^+}$ 的检验方法：取样品溶于水，加入 NaOH 溶液并加热，生成能使湿润红色石蕊试纸变蓝的气体。

# 硝酸与硝酸盐

## 硝酸

### 物理性质

硝酸是无色、易挥发、有刺激性气味、极易溶于水的液体。

### 化学性质

**酸的通性**（硝酸是强氧化性酸，只有酸的部分通性）。

**强氧化性**：
- 铁、铝遇冷的浓硝酸会钝化。
- 铁与稀硝酸反应：
  - Fe 少量：$\mathrm{Fe + 4HNO_3(稀) = Fe(NO_3)_3 + NO \uparrow + 2H_2O}$
  - Fe 过量：$\mathrm{3Fe + 8HNO_3(稀) = 3Fe(NO_3)_2 + 2NO \uparrow + 4H_2O}$
- 铜与硝酸反应：
  - $\mathrm{Cu + 4HNO_3(浓) = Cu(NO_3)_2 + 2NO_2 \uparrow + 2H_2O}$
  - $\mathrm{3Cu + 8HNO_3(稀) = 3Cu(NO_3)_2 + 2NO \uparrow + 4H_2O}$

浓硝酸和浓盐酸以体积比1:3混合即得王水。王水可以溶解不溶于硝酸的铂、金。

与非金属单质反应：
- $\mathrm{C + 4HNO_3(浓) \xlongequal{\triangle} CO_2 \uparrow + 4NO_2 \uparrow + 2H_2O}$
- $\mathrm{P + 5HNO_3(浓) \xlongequal{\triangle} H_3PO_4 + 5NO_2 \uparrow + H_2O}$

与化合物反应：$\mathrm{3Fe^{2+} + NO_3^- + 4H^+ = NO \uparrow + 3Fe^{3+} + 2H_2O}$

**受热不稳定性**：$\mathrm{4HNO_3(浓) \xlongequal{\triangle} 4NO_2 \uparrow + O_2 \uparrow + 2H_2O}$（浓硝酸见光会分解，应保存在棕色试剂瓶中）

**硝化反应**：$\mathrm{C_6H_6 + HNO_3(浓) \xrightarrow{浓硫酸} C_6H_5NO_2 + H_2O}$

### 工业制备

- $\mathrm{3H_2 + N_2 \xrightleftharpoons[高温、高压]{催化剂} 2NH_3}$
- $\mathrm{4NH_3 + 5O_2 \xrightleftharpoons[催化剂]{\triangle} 4NO + 6H_2O}$
- $\mathrm{2NO + O_2 = 2NO_2}$
- $\mathrm{4NO_2 + O_2 + 2H_2O = 4HNO_3}$

## 硝酸盐

硝酸盐的溶解度偏大，且溶于水会吸收大量的热。硝酸盐受热易分解：$\mathrm{2AgNO_3 \xlongequal{\triangle} O_2 \uparrow + 2NO_2 \uparrow + 2Ag}$

# 磷及其化合物

## 磷单质

P 元素的最低化合价为 $-3$，最高化合价为 $+5$，较稳定的化合价为 $+5$ 价。磷单质有多种同素异形体，常见的是红磷和白磷。红磷稳定性远大于白磷。白磷（$\mathrm{P_4}$）分子结构为正四面体形，有很强的还原性，易自燃，需放在水中保存。

磷的燃烧：$\mathrm{4P + 5O_2 \xlongequal{点燃} 2P_2O_5}$、$\mathrm{2P + 3Cl_2 \xlongequal{点燃} 2PCl_3}$

## 磷的氧化物

$\mathrm{P_4O_6}$、$\mathrm{P_4O_{10}}$（简写成 $\mathrm{P_2O_3}$、$\mathrm{P_2O_5}$），均为酸性氧化物。$\mathrm{P_2O_5}$ 是实验室常用的酸性干燥剂，但不能作为食品干燥剂。

$\mathrm{PH_3}$ 具有极强还原性，在空气中易自燃：$\mathrm{2PH_3 + 4O_2 \xlongequal{点燃} P_2O_5 + 3H_2O}$

## 含磷的酸

| 名称 | 次磷酸 | 亚磷酸 | （正）磷酸 |
| :--- | :--- | :--- | :--- |
| 化学式 | $\mathrm{H_3PO_2}$ | $\mathrm{H_3PO_3}$ | $\mathrm{H_3PO_4}$ |
| 类别 | 一元酸 | 二元酸 | 三元酸 |

$\mathrm{H_3PO_2}$、$\mathrm{H_3PO_3}$ 是强还原性酸；$\mathrm{H_3PO_4}$ 是高沸点酸，实验室可用 $\mathrm{H_3PO_4}$ 制备挥发性酸。

## 含磷的盐

磷酸盐的溶解度：磷酸盐只溶钾、钠、铵盐。$\mathrm{NaH_2PO_4}$ 的水溶液显酸性，$\mathrm{Na_2HPO_4}$ 的水溶液显碱性。

## 磷的氯化物

$\mathrm{PCl_3}$、$\mathrm{PCl_5}$ 极易水解：
- $\mathrm{PCl_3 + 3H_2O = 3HCl + H_3PO_3}$
- $\mathrm{PCl_5 + 4H_2O = 5HCl + H_3PO_4}$
