# 原电池的基本概念

## 定义

原电池是将**化学能**直接转化为**电能**的装置。其核心原理是自发的氧化还原反应（即存在电势差）通过外电路形成电流，从而实现能量的转换。

## 组成成分

一个完整的原电池通常由以下三部分构成：

1.  **外电路**：
    -   由**导线**和**负载**（如灯泡、用电器）组成。
    -   作用是传导电子，形成电流。电子从负极（失电子）经导线流向正极（得电子），电流方向则相反（从正极到负极）。
2.  **内电路**：
    -   由**电解质溶液**（或熔融电解质）组成。
    -   作用是传导离子，使电荷守恒。内电路中，阳离子向正极迁移，阴离子向负极迁移。
3.  **盐桥**（非必须，但高效电池常有）：
    -   通常为装有饱和 KCl 溶液（或 KNO₃、NH₄NO₃溶液）的 U 形管，两端用琼脂封口。
    -   **作用**：① 连接两个半电池，使内电路导通；② 平衡电荷（通过离子的定向移动），维持溶液的电中性，使反应持续进行；③ 避免两种电解质溶液直接接触，防止副反应发生。
    -   **注意**：若两个电极插入同一电解质溶液中，则无需盐桥（如单液原电池）。

## 形成条件（缺一不可）

1.  **有自发进行的氧化还原反应**（根本驱动力）。
2.  **有两个活性不同的电极**（通常为导体，或金属与非金属导体，如石墨）。
    -   若两电极材料相同，则不能构成原电池（除非两极接触的电解质溶液不同，如氢氧燃料电池可用相同材料）。
3.  **电极均插入电解质溶液（或熔融电解质）中**，形成闭合的内电路。
4.  **用导线将两电极连接起来**（或用导线连接后接用电器），形成闭合的外电路。

## 正负极判断

| 负极                    | 正极                    |
| :-------------------- | :-------------------- |
| 物质失电子、发生氧化反应、化合价升高的一极 | 物质得电子、发生还原反应、化合价降低的一极 |
| 外电路中电子流出的一极           | 外电路中电子流入的一极           |
| 内电路中阴离子移向的一极          | 内电路中阳离子移向的一极          |
| 电势低的一极                | 电势高的一极                |

正、负极是矛盾关系，由于矛盾的对立性，正、负极的特征往往相反。为了事半功倍，重点记忆某一极的特征即可。矛盾既对立又统一，正极得电子总数与负极失电子总数相等。注意学科之间的联系，充分利用物理学中的电学知识来理解并掌握电化学知识。

## 原电池原理的应用

**金属活动性比较**：一般情况下，负极金属单质的活泼性强于正极。

高中有两个重要例外，活泼性弱的金属单质作负极：
- Al 可以与 NaOH 溶液反应而 Mg 不行，因此 Mg、Al 用导线相连放入 NaOH 溶液所构成的原电池，活泼性较弱的 Al 反而为负极。
- 常温下，Fe、Al 遇浓硝酸会钝化，Fe、Cu（或 Al、Cu）用导线相连放入冷的浓硝酸所构成的原电池，活泼性较弱的 Cu 反而为负极。

由于环境会一定程度地影响金属的活泼性，所以做电化学的题目时，一定要注意环境的影响。

**加快化学反应速率**：纯金属和酸反应比较慢，当加入少量比该金属更惰性的金属形成原电池后，会加速该金属与酸的反应。

**金属防腐**：为了避免某金属的腐蚀（金属单质失电子被氧化），可以将该金属与比其更活泼的其他金属相连，该金属作为原电池的正极而被保护，该方法称为牺牲阳极法。

一般而言，在原电池装置中，电极分正、负极；在电解池中，电极分阴、阳极。但在电化学的广义范畴中，只要是失电子的一极均可称为阳极，得电子的一极均可称为阴极。

## 原电池的设计

利用氧化还原反应原理设计高效的原电池装置（含盐桥），设计流程如下：

第一步：先分析总反应，寻找氧化剂、还原剂和环境。

第二步：选择正、负极材料
- 若氧化剂、还原剂是固体，则一般直接作正极、负极材料。电解质选不直接和电极发生反应的电解质溶液即可。
- 若氧化剂、还原剂为溶液中的某种粒子，则二者分别为两个“半电池”的正极、负极对应的电解质溶液。电极选导电而又不会与电解质反应的导体即可（常用石墨或 Pt 作辅助电极）。
- 若氧化剂、还原剂是气体，则需要寻找 Pt 或石墨载体（燃料电池的两个电极材料可以相同），将气体分别通入正极、负极。电解质选不直接和电极以及气体发生反应的电解质溶液即可。

第三步：选择合适的溶液（多数时候可选饱和 KCl 溶液）构成盐桥。

第四步：用盐桥将内电路连接，用导线将两个电极连通构成外电路。

第五步：画出总装置图即可。

原电池装置不一定有盐桥，但高效的原电池以及氧化剂和还原剂均为溶液的电池一般需要盐桥连接内电路。

# 燃料电池

## 燃料电池概述

燃料电池是一种能连续将燃料和氧化剂的化学能转化成电能的化学电源。燃料电池的正、负极往往是 Pt 或石墨，负极通入的是燃料（还原剂），正极通入助燃剂（氧化剂）。燃料电池总反应不写“燃烧”，因为没有燃烧过程，化学能主要转化成了电能，少部分以热能形式损失。

由于反应物连续不断进入，而生成物持续排出，所以燃料电池容量极大。其极大地提高了能源利用率，又称为“绿色发电站”。

## 燃料电池电极反应式书写方法

书写燃料电池电极反应式时，务必考虑环境的影响。环境会影响最终的生成物和调平电荷的粒子，不同环境下电极反应式完全不同。有机燃料电池中，负极通燃料（即有机物），正极通助燃剂（即氧气）。有机物的氧化产物一般为+4 价 C，环境决定氧化产物的最终存在形态是 $\mathrm{CO_2}$ 还是 $\mathrm{CO_3^{2-}}$；环境也决定了氧气的最终还原产物可能是 $\mathrm{H_2O}$、$\mathrm{OH^-}$、$\mathrm{O^{2-}}$、$\mathrm{CO_3^{2-}}$ 中的其中一种。

书写步骤：
1. 先写出电极反应式架构（变价元素守恒）
2. 根据环境用相应离子调平电荷（酸性用 $\mathrm{H^+}$，碱性用 $\mathrm{OH^-}$，熔融碳酸盐用 $\mathrm{CO_3^{2-}}$，固体氧化物用 $\mathrm{O^{2-}}$）
3. 最后“看 H 补 $\mathrm{H_2O}$，用 O 检查”完成 H、O 元素守恒

## 氢氧燃料电池

| 分类 | 电极 | 电极反应式 |
| :--- | :--- | :--- |
| 酸性 | 负极 | $\mathrm{2H_2 - 4e^- = 4H^+}$ |
| 酸性 | 正极 | $\mathrm{O_2 + 4e^- + 4H^+ = 2H_2O}$ |
| 碱性 | 负极 | $\mathrm{2H_2 - 4e^- + 4OH^- = 4H_2O}$ |
| 碱性 | 正极 | $\mathrm{O_2 + 4e^- + 2H_2O = 4OH^-}$ |
| 中性 | 负极 | $\mathrm{2H_2 - 4e^- = 4H^+}$ |
| 中性 | 正极 | $\mathrm{O_2 + 4e^- + 2H_2O = 4OH^-}$ |

总反应均为：$\mathrm{2H_2 + O_2 = 2H_2O}$

## 乙醇燃料电池

**酸性环境**：
- 负极：$\mathrm{C_2H_5OH - 12e^- + 3H_2O = 2CO_2 \uparrow + 12H^+}$
- 正极：$\mathrm{O_2 + 4e^- + 4H^+ = 2H_2O}$

**碱性环境**：
- 负极：$\mathrm{C_2H_5OH - 12e^- + 16OH^- = 2CO_3^{2-} + 11H_2O}$
- 正极：$\mathrm{O_2 + 4e^- + 2H_2O = 4OH^-}$

**熔融碳酸盐环境**：
- 负极：$\mathrm{C_2H_5OH - 12e^- + 6CO_3^{2-} = 8CO_2 \uparrow + 3H_2O}$
- 正极：$\mathrm{O_2 + 4e^- + 2CO_2 = 2CO_3^{2-}}$

## 丙烷燃料电池

**碱性环境**：
- 负极：$\mathrm{C_3H_8 - 20e^- + 26OH^- = 3CO_3^{2-} + 17H_2O}$
- 正极：$\mathrm{5O_2 + 20e^- + 10H_2O = 20OH^-}$
- 总反应：$\mathrm{C_3H_8 + 5O_2 + 6OH^- = 3CO_3^{2-} + 7H_2O}$

**熔融碳酸盐环境**：
- 负极：$\mathrm{C_3H_8 - 20e^- + 10CO_3^{2-} = 13CO_2 + 4H_2O}$
- 正极：$\mathrm{5O_2 + 20e^- + 10CO_2 = 10CO_3^{2-}}$
- 总反应：$\mathrm{C_3H_8 + 5O_2 = 3CO_2 + 4H_2O}$

**固体氧化物环境**：
- 负极：$\mathrm{C_3H_8 - 20e^- + 10O^{2-} = 3CO_2 + 4H_2O}$
- 正极：$\mathrm{5O_2 + 20e^- = 10O^{2-}}$
- 总反应：$\mathrm{C_3H_8 + 5O_2 = 3CO_2 + 4H_2O}$

## 肼燃料电池（碱性）

- 负极：$\mathrm{N_2H_4 - 4e^- + 4OH^- = N_2 + 4H_2O}$
- 正极：$\mathrm{O_2 + 4e^- + 2H_2O = 4OH^-}$
- 总反应：$\mathrm{N_2H_4 + O_2 = N_2 + 2H_2O}$

由于氮的稳价为 0 价，所以燃料电池中氮元素的产物往往为 $\mathrm{N_2}$。

## 微生物燃料电池

利用微生物将有机物中的化学能直接转化成电能的装置。在无氧的负极室中，微生物将有机物分解并释放电子和质子。可看成有机物的酸性燃料电池。微生物的生存对温度、pH、氧气有一定要求。

# 一次电池

## 碱性锌锰干电池

碱性锌锰干电池比酸性锌锰干电池性能好，它的比能量和可储存时间均有所提高，是普通锌锰干电池的升级换代产品。

结构：负极为 Zn，正极为 $\mathrm{MnO_2}$，电解质溶液为 KOH。

电极反应：
- 负极：$\mathrm{Zn - 2e^- + 2OH^- = Zn(OH)_2}$
- 正极：$\mathrm{2MnO_2 + 2e^- + 2H_2O = 2MnO(OH) + 2OH^-}$
- 总反应：$\mathrm{Zn + 2MnO_2 + 2H_2O = Zn(OH)_2 + 2MnO(OH)}$

由于 $\mathrm{Zn(OH)_2}$ 是弱碱，温度稍高可脱水生成 $\mathrm{ZnO}$，所以负极反应式也可以写成：$\mathrm{Zn - 2e^- + 2OH^- = ZnO + H_2O}$。

由于 $\mathrm{Zn(OH)_2}$ 具有两性，若 KOH 的浓度过高且物质的量过多，则 $\mathrm{Zn(OH)_2}$ 会转化成 $\mathrm{[Zn(OH)_4]^{2-}}$。对应的负极反应式为 $\mathrm{Zn - 2e^- + 4OH^- = [Zn(OH)_4]^{2-}}$。因此在书写电极反应式时，一定要仔细阅读题干信息和图像信息，确定负极的主要产物和主要反应。

一般同时书写正、负极反应时，需要遵循得失电子守恒。若只单写某一极反应，则不需要和另一极得失电子守恒。所以只写碱性锌锰干电池正极反应时，可以写成：$\mathrm{MnO_2 + e^- + H_2O = MnOOH + OH^-}$。

# 二次电池

## 铅酸蓄电池

铅酸蓄电池的优点是电压稳定、使用方便、安全可靠、价格低廉，因此在生产、生活中使用广泛。缺点是比能量低、笨重、保养要求严格、废弃后易污染环境。

结构：负极为 Pb，正极为 $\mathrm{PbO_2}$，电解质溶液为稀硫酸。

放电过程：
- 负极：$\mathrm{Pb - 2e^- + SO_4^{2-} = PbSO_4}$
- 正极：$\mathrm{PbO_2 + 2e^- + SO_4^{2-} + 4H^+ = PbSO_4 + 2H_2O}$
- 总反应：$\mathrm{Pb + PbO_2 + 2SO_4^{2-} + 4H^+ = 2PbSO_4 + 2H_2O}$

充电过程：
- 阴极：$\mathrm{PbSO_4 + 2e^- = Pb + SO_4^{2-}}$
- 阳极：$\mathrm{PbSO_4 - 2e^- + 2H_2O = PbO_2 + SO_4^{2-} + 4H^+}$
- 总反应：$\mathrm{2PbSO_4 + 2H_2O \xlongequal{电解} Pb + PbO_2 + 2SO_4^{2-} + 4H^+}$

充电时电极的连接：外接电源负极接铅酸蓄电池负极（阴极），外接电源正极接铅酸蓄电池正极（阳极）。

## 锂离子电池

锂离子电池的优点是工作寿命长、小型化、供电方便。缺点是锂资源受限、成本较高、耐高温性较差。

结构：负极为 $\mathrm{Li_xC_y}$，正极为 $\mathrm{LiCoO_2}$（钴酸锂），电解质溶液为 $\mathrm{LiPF_6}$（六氟磷酸锂）的碳酸酯溶液（无水）。

$\mathrm{Li_xC_y}$ 中的 $\mathrm{C_y}$ 表示石墨，$\mathrm{Li_xC_y}$ 表示嵌入了 Li 的石墨材料（石墨本身不参与放电，可将石墨看作载体），所以 C、Li 的化合价均看作 0 价。

放电时，石墨中的 Li 放电形成 $\mathrm{Li^+}$，移向正极，嵌入钴酸锂晶体中，Li 从石墨中脱嵌；充电时，$\mathrm{Li^+}$ 从钴酸锂晶体中脱嵌，移向负极，发生还原反应生成 Li，嵌入石墨。这样在放电、充电时，$\mathrm{Li^+}$ 往返于电池的正极、负极之间，完成化学能与电能的相互转化。

放电过程：
- 负极：$\mathrm{Li_xC_y - xe^- = xLi^+ + C_y}$
- 正极：$\mathrm{Li_{1-x}CoO_2 + xLi^+ + xe^- = LiCoO_2}$
- 总反应：$\mathrm{Li_xC_y + Li_{1-x}CoO_2 = LiCoO_2 + C_y}$

充电过程：
- 阴极：$\mathrm{xLi^+ + C_y + xe^- = Li_xC_y}$
- 阳极：$\mathrm{LiCoO_2 - xe^- = Li_{1-x}CoO_2 + xLi^+}$
- 总反应：$\mathrm{C_y + LiCoO_2 \xlongequal{电解} Li_xC_y + Li_{1-x}CoO_2}$

# 高频考查的原电池题型

## PH 变化问题

判断原电池中电解质溶液 pH 变化的方法：

一、若求电极周围溶液的 pH 变化，则只考虑电极反应本身，不考虑离子的移动。

二、若求工作一段时间后，某极周围溶液 pH 变化，要考虑离子的移动。

三、若求工作一段时间后，整个溶液 pH 变化，主要考虑总反应，既要考虑酸碱的生成与消耗，还要考虑水的生成与消耗。

## 浓差电池

利用某些特定离子的浓度差产生电势差的一种装置。为了限定某些离子的移动，需用到“离子交换膜”。离子移动的方向遵循“高浓度到低浓度”，且“阴离子移向负极，阳离子移向正极”。

## 含双极膜的原电池

离子交换膜的作用：既可以将两极区隔离，防止两极物质反应，又可以让某特定离子移动，平衡电荷的同时形成闭合回路。

双极膜：由一张阳膜和一张阴膜复合制成的阴、阳复合膜。原电池工作时，复合层中间的水解离成 $\mathrm{H^+}$ 和 $\mathrm{OH^-}$，$\mathrm{H^+}$ 通过阳膜移向正极、$\mathrm{OH^-}$ 通过阴膜移向负极（离子移动遵守“正正负负”）。通过双极膜的离子、通过外电路的电子以及解离水分子的关系式为 $1\mathrm{H^+} \sim 1\mathrm{OH^-} \sim 1\mathrm{e^-} \sim 1\mathrm{H_2O}$。

## 多室原电池

多室、多交换膜的分析方法：
一、根据装置最终目的，确定每个室的作用。
二、根据每个室离子浓度的相对大小确定离子移动的方向以及离子交换膜的种类。
三、根据离子移动的方向可以确定放电时的正、负极（或充电时的阴、阳极）。

## 有机化学与原电池综合

有机物的化合价处理方法：
- 若有机物只有一个碳周围的化学键发生变化，则直接分析该碳的真实化合价。
- 若有机物很多碳周围的化学键发生变化，则用分子式分析碳的平均化合价。
- 若有机物只有氢原子或者氧原子的变化，直接分析组成即可得化合价变化。得氧或失氢化合价升高，得氢或失氧化合价降低，每个氧对应变 2 价，每个氢对应变 1 价。
- 若有机物组成上只有 $\mathrm{Na^+}$ 或 $\mathrm{K^+}$ 个数的变化，则 $\mathrm{Na^+}$ 或 $\mathrm{K^+}$ 减少的个数即负极或阳极失电子的个数。$\mathrm{Na^+}$ 或 $\mathrm{K^+}$ 增加的个数即正极或阴极得电子的个数。
