# 文章例题格式规范

> 适用范围：`public/blogs/` 下的 Markdown 文章。
> 保证题目被**答题、批阅、答案设置、答题卡、错题本**正确解析。

---

## 一、占位符

| 占位符 | 作用 | 渲染 |
|--------|------|------|
| `【@】` / `【@N】` | 答题占位符：插入答题卡片 | 答题卡片（右上角显示题号角标） |
| `【题干N】` | 题干占位符：标记第 N 题的题干 | 题号标签「第 N 题」 |
| `【题干N-M】` | 公共题干占位符：标记第 N~M 题的公共题干（大题） | 题号标签「第 N-M 题」；与小题同栏时自动用大框包住 |

- **只有这几种全角写法有效**；`[@1]`、`【@ 1 】` 等不再识别，会原样显示在正文。
- **编号前后允许空格**（`【题干 1】`、`【题干 5-6 】` 均可）。
- `【@N】` 单独占一行；N 为题目编号，全篇唯一。
- `【题干N】` 的 N 必须对应存在的题目；同一题可多处标记，错题本按出现顺序拼接。
- `【题干N-M】` 的 N、M 必须是对应存在的题目编号，且 N ≤ M；区间内每题的错题本内容都包含该公共片段。

## 二、基本布局

### 布局 A：知识点与例题的双栏布局

左栏写知识点内容，`---` 分隔后右侧（侧栏）写例题。注意题干内容不再需要文本序号。

注意选项不再需要缩进。

```markdown
正文知识点……

---

【题干1】题干内容……

A. 选项一
B. 选项二

【@1】

【题干2】题干内容

【@2】

---

正文知识点……
```

### 布局 B：仅有例题，题干与答题区双栏布局

左侧（主栏）写题干，`---` 分隔后右侧（侧栏）只写答题占位符：

```markdown
# 章节标题

【题干1】题干内容……

---

【@1】
【@2】

---
```

### 公共题干：几道题共属一个大题

用 `【题干N-M】` 标记公共题干（如阅读材料、大题总要求），再给每题补各自的 `【题干N】`：

```markdown
# 完形填空

【题干1-10】I was required to read one of Bernie Siegel' s books and was hooked.

---

【题干1】1. A. ideas  B. notes  C. memories  D. tastes

【@1】

【题干2】2. A. push  B. strike  C. impact  D. challenge

【@2】

【题干3】3. A. refer to  B. get through  C. learn from  D. go over

【@3】
```

错题本收集：每题的题干 = **公共题干 + 该题自己的题干**（如第 2 题 = 材料 + "2. A. push …"）。

> 提示：公共题干片段截止到**下一个占位符**为止。若公共题干后紧跟着某题的内容，这些内容会进入公共片段。所以推荐"公共题干 + 每题各自 `【题干N】`"的组合写法。
>
> 页面效果：题干占位符显示为题号标签（如「第 1-3 题」）；公共题干与其小题**在同一栏**（之间没有 `---`）时，会自动用一个大框框住整个大题，仅起视觉分组作用。

## 三、编号规则

| 规则 | 说明 |
|------|------|
| 全篇唯一 | `【@N】` 编号不可重复，跨章节也唯一 |
| 题干对应题目 | `【题干N】` 的 N 必须是存在的题目编号，否则仅隐藏、不归属 |
| 推荐显式编号 | `【@1】`、`【题干1】`；自动编号 `【@】` 也可用（按出现顺序从 1 开始） |
| 发布后不改号 | 提交、批阅、错题记录都按编号存储；新增题目追加新编号 |

---

## 四、章节与双栏规则

| 元素 | 规则 |
|------|------|
| `#` 一级标题 | 章节单元，答题卡按它分组 |
| `###` 三级标题 | 推荐用作每道题的小标题（`### 例题 1`） |
| `---` 分隔线 | 每个一级章节内**最多成对使用**（第一个开启侧栏，第二个关闭） |

---

## 五、错题本收集规则

| 书写方式 | 收集到的内容 |
|----------|--------------|
| 写了 `【题干N】` | 全部题干片段按出现顺序拼接（自动排除标题、分隔线、空行） |
| 写了 `【题干N-M】` | 公共片段进入区间内每题（+ 各自的 `【题干N】` 片段） |
| 未写标记 | 「最近一级章节标题 · 第N题」 |
| 超过 400 字符 | 截断为前 400 字 |

---

## 六、常见错误

| ❌ 错误 | ✅ 正确 |
|--------|--------|
| `【@1】这是第一道题`（占位符与文字同行） | 题干在上，`【@1】` 独立一行 |
| `【@3】` 重复出现 | 编号全篇唯一 |
| `【题干5】` 对应不存在的第 5 题 | N 必须与某道题一致 |
| `【题干5-2】`（区间写反）或区间超出题目范围 | N ≤ M，且两端都必须是存在的题目 |
| 用 `[@1]`、`【@ 1 】` | 只认 `【@】` / `【@N】` / `【题干N】` / `【题干N-M】` |
| 标准答案写进文章 | 在管理员「设置答案」模式中填写 |

---

## 七、自检清单

- [ ] `【@N】` 单独占一行，编号全篇唯一
- [ ] 题干写在 `【题干N】` 之后（或按布局 B 放在左侧栏）
- [ ] 大题公共题干用 `【题干N-M】`，且每题补了各自的 `【题干N】`
- [ ] `---` 每个一级章节内成对使用（最多 2 个）
- [ ] 文章中没有写标准答案
- [ ] 发布后不改编号、不删题
