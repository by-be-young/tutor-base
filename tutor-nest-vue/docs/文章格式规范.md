# 文章例题格式要求合集（含 A、B 模式）

本文档汇总了针对 `public/articles/` 下 Markdown 文章的全部定制要求，涵盖**布局 A（知识点与例题双栏）**和**布局 B（纯题目集）**两种模式。

---

## 一、通用全局规则（A、B 模式均适用）

### 1. 标题与元数据
| 项目 | 要求 |
|------|------|
| **顶部总标题** | **不要**写章节总标题（如 `# 第11章 电化学`），直接写模块标题 |
| **模块/知识点标题** | 使用一级标题 `# 标题名称` |
| **页码** | **全部删除**（如 `答案: P110`） |
| **来源信息** | **全部删除**（年份、省份、难度星级、节选字样） |

### 2. 化学式与 KaTeX
所有化学式、离子式、电极反应式、总反应必须用 `$...$` 包裹。

✅ 示例：`$O_2 - 4e^- + 2H_2O = 4OH^-$`

### 3. 括号与填空
| 场景 | 格式 |
|------|------|
| **选择题**题干末尾括号 | 空白括号 `（ ）` |
| **填空题**需填写位置 | 下划线 `______` |

✅ 示例：`下列说法不正确的是（ ）` 和 `电极反应式为 ______。`

### 4. 选项排版
四个选项（A、B、C、D）之间**各空一行**（每个选项后加一个空行）。

### 5. 大题（组合题）规范
- 使用公共题干 `【题干N-M】` 包住总要求。
- 每个小问拆分为独立的 `【题干N】`，每个子题拥有独立的 `【@N】`。

✅ 示例：
```markdown
【题干9-11】按要求回答下列问题：

【题干9】(1) a 电极的电极反应式为 ______。
【@9】

【题干10】(2) 盐桥中 K+ 移向装置的 ______。
【@10】
```

### 6. Markdown 间距
所有块级元素（标题、段落、题干、选项、分隔线、占位符）之间**必须空一行**。

### 7. 编号规则
编号 `N`（如 `【题干N】`、`【@N】`）**全篇唯一且连续**（从 1 开始）。

---

## 二、布局 A：知识点与例题双栏布局（定制版）

> 适用场景：知识点讲解与例题穿插，边学边练。

### 核心规则
1.  **一个 `#`（一级标题）最多只能有一对 `---`（即最多一个例题区）**。
2.  若同一大主题下有多段知识点需要分别配例题，**必须拆分为多个独立的一级标题**（如 `# 原电池的工作原理`、`# 原电池的应用`）。
3.  每个 `#` 标题下：
    - 先写知识点内容（左栏）。
    - `---` 分隔线（开启右侧例题栏）。
    - 写该部分对应的所有例题（题干 + 紧随其后的 `【@N】` 交替出现）。
    - 例题结束，需加 `---` 关闭右侧栏。

### 完整示例
```markdown
# 原电池的工作原理

原电池是将化学能转化为电能的装置。负极发生氧化反应，正极发生还原反应。电子从负极经外电路流向正极。

---

【题干1】一种锂-空气电池的工作原理如图所示，下列说法不正确的是（ ）

A. 金属锂作电池的负极

B. 电子由金属锂经负载流向石墨烯

C. 石墨烯表面发生的电极反应：$O_2 - 4e^- + 2H_2O = 4OH^-$

D. 每消耗 $1\ \text{mol}\ O_2$，金属锂电极质量减少 $28\ \text{g}$

【@1】

【题干2】铅酸蓄电池工作时，硫酸溶液中的 $H^+$ 向 $PbO_2$ 电极移动。下列说法正确的是（ ）

A. 铅酸蓄电池和氢氧燃料电池都属于二次电池

B. 氢氧燃料电池负极消耗 $22.4\ \text{L}$ 气体时，电路中通过的电子数为 $2N_A$

C. 铅酸蓄电池工作时，$H^+$ 向 $PbO_2$ 电极移动

D. 稀硫酸可用稀盐酸代替降低成本

【@2】

---

# 原电池的应用

铅酸蓄电池和锂离子电池是当前应用最广泛的两种二次电池。锂离子电池具有能量密度高的特点。

---

【题干3】某锂离子电池放电时总反应为 $Li_xC_y + Li_{1-x}CoO_2 = LiCoO_2 + C_y$，下列说法错误的是（ ）

A. 离子液体具有良好的导电性，可作为该电池的电解质

B. 交换膜为阳离子交换膜

C. 充电时，阳极 $LiCoO_2$ 中钴元素化合价降低

D. 放电时，每转移 $1\ \text{mol}$ 电子，负极质量减少 $7\ \text{g}$

【@3】

---
```

## 三、布局 B：题干与答题区分离（纯题目集）

> 适用场景：只有题目，不需要知识点讲解，统一作答。

### 核心规则
1.  一个 `#`（一级标题）对应一个独立的题目模块（如 `# 模块1 原电池`）。
2.  该模块下：先罗列所有 `【题干N】`（主栏）。
3.  然后一个 `---` 分隔线，切换到侧栏答题区。
4.  答题区集中列出该模块所有题目的 `【@N】`，**答题区末尾也要加 `---`** 作为结束。

### 完整示例
```markdown

D. 每消耗 $1\ \text{mol}\ O_2$，金属锂电极质量减少 $28\ \text{g}$

【题干2】铅酸蓄电池多用于启动和维持汽车用电系统的正常运转，氢氧燃料电池可以连续不断地提供电能作为汽车的动力能源。下列说法正确的是（ ）

A. 铅酸蓄电池和氢氧燃料电池都属于二次电池

B. 氢氧燃料电池负极消耗 $22.4\ \text{L}$ 气体时，电路中通过的电子数为 $2N_A$

C. 铅酸蓄电池工作时，硫酸溶液中的 $H^+$ 向 $PbO_2$ 电极移动

D. 考虑经济性，铅酸蓄电池中的稀硫酸可用稀盐酸代替降低成本

【@2】
```

## 四、模式 A 与 B 核心区别对照表

| 对比项 | 布局 A（双栏混合） | 布局 B（题干与答题区分） |
| :--- | :--- | :--- |
| **内容性质** | 知识点 + 例题穿插 | 纯题目集 |
| **一个 `#` 可含几个例题区？** | **最多 1 个**（即最多一对 `---`） | 最多 1 个（即最多一对 `---`） |
| **多段内容如何处理？** | 拆分为多个 `#` 标题，各自配例题 | 拆分为多个 `#` 标题，各自配答题区 |
| **答题占位符位置** | 穿插在侧栏中，紧随对应题干之后 | 全部集中在模块末尾的独立答题区 |
| **答题区末尾分隔线** | 不需要（每个题紧跟答题卡） | **必须加** `---`（用于封闭答题区） |
| **典型流程** | 知识点 → `---` → 题1 + 【@1】、题2 + 【@2】 → （结束） | 题1、题2 → `---` → 【@1】、【@2】 → `---` |

---

## 五、通用检查清单

- [ ] 无顶部总标题（如 `# 第X章`）
- [ ] 无页码、无来源信息
- [ ] 所有化学式用 `$...$`（KaTeX）
- [ ] 选择题括号为空白 `（ ）`，填空题用 `______`
- [ ] 四个选项之间各空一行
- [ ] 组合题用 `【题干N-M】` + 独立子题 `【题干N】`
- [ ] 所有块级元素之间空一行
- [ ] 编号全篇唯一且连续
- [ ] 布局 A：每个 `#` 最多一对 `---`；多段内容已拆分为多个 `#` 标题
- [ ] 布局 B：每个 `#` 独立对应一个答题区，且答题区末尾有 `---`
