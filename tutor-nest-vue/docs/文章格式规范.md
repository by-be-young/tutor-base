# 课件（Markdown 文章）格式规范

本文档是 `tutor-nest-vue/public/articles/` 下全部课件的**唯一格式契约**。课件解析器
（[`src/utils/questionText.js`](../src/utils/questionText.js)）与错题本、错题训练、课件详情页都按本文实现；
任何格式变更必须同时改本文、解析器、[`test/questionText.test.js`](../test/questionText.test.js) 与
[`scripts/check-courseware.mjs`](../scripts/check-courseware.mjs)。

> 为什么需要规范：错题本只存「课件 id + 题目编号 + 我的作答」，**题干在展示时由课件原文现场解析**。
> 一旦课件没有可定位的题干，错题本就只能显示「模块名 · 第 N 题」，等于丢失题目。

---

## 一、占位符：两个标记撑起全部题目

| 标记 | 写法 | 作用 |
| --- | --- | --- |
| 作答占位符 | `【@N】` | 生成一张答题卡，`N` 是**题目编号**（错题本、答案键都用它做外键） |
| 作答占位符（旧写法） | `【@】` | 按出现顺序自动编号，等价于 `【@1】`、`【@2】`…；**新课件不再使用** |
| 题干标记 | `【题干N】` | 该标记之后、下一个占位符之前的内容就是第 `N` 题的题干 |
| 公共题干标记 | `【题干N-M】` | 区间内每道题共享同一段材料（大题引导语、阅读材料、实验描述） |

解析完成后，每道题的题干按下列优先级产生（`analyzeCourseware` 的 `source` 字段）：

1. `stem`：命中 `【题干N】` / `【题干N-M】`——**这是唯一的规范写法**。
2. `nearby`：作答占位符上方紧邻的题目段落（兼容旧课件，见 §六）。
3. `fallback`：`「最近一级章节标题 · 第N题」`——**等于题干丢失**，校验工具会报错。

> 标记内的编号前后允许空格：`【题干 5】` 与 `【题干5】` 等价；新写的课件统一不带空格。

### 1.1 题干边界规则

题干片段 = `【题干N】` 之后 → 下一个占位符（`【题干…】` 或 `【@…】`）之前的内容，并遵守：

- **不跨分隔线**：遇到独占一行的 `---` 立即结束。`---` 之后是作答区，答题区里的 `1.`、`(1)` 等
  标签永远不属于题干。
- 自动丢弃：空行、`#` 标题行、`---` 分隔线、行首引用符号 `> `、`**加粗**`、反引号。
- 保留：`$…$` 公式、`![[图片]]`、`|` 表格、`______` 填空线、`A./B./C./D.` 选项行。
- 超过 400 字符按行截断（必要时退到最后一个完整公式），末尾补 `…`；卡片上的「查看原文」可回到全文。

### 1.2 编号规则

| 规则 | 级别 | 说明 |
| --- | --- | --- |
| `【@N】` 编号唯一 | 必须 | 重复编号会让两道题读写同一份答案键 |
| `【题干N】` 与 `【@N】` 一一对应 | 必须 | 有题干没作答 = 学生无法作答；有作答没题干 = 错题本丢题干 |
| 编号与作答占位符出现在同一份课件 | 必须 | 题干可以写在任意位置（跨栏、跨段），但必须在同一文件内 |
| 编号从 1 开始连续 | 推荐 | 历史课件允许缺号：**重排编号会让已录入的答案键失配，必须同时重录** |
| 不使用 `【@】` 自动编号 | 推荐 | 任何一次增删题都会让后续编号整体位移 |

## 二、通用排版规则（所有布局适用）

### 2.1 标题与元数据

| 项目 | 要求 |
| --- | --- |
| 顶部总标题 | **不要**写章节总标题（如 `# 第11章 电化学`），直接写模块标题 |
| 模块/知识点标题 | 一级标题 `# 标题名称`；一个 `#` = 一个模块 = 一个答题区 |
| 页码、来源信息 | **全部删除**（`答案: P110`、年份、省份、难度星级、节选字样） |

### 2.2 化学式与公式

所有化学式、离子式、电极反应式、总反应必须用 `$...$` 包裹：

✅ `$O_2 - 4e^- + 2H_2O = 4OH^-$`

### 2.3 括号与填空

| 场景 | 格式 |
| --- | --- |
| 选择题题干末尾括号 | 空白括号 `（ ）` |
| 填空题作答位置 | 下划线 `______`（题干内保留，答题卡另由 `【@N】` 生成） |

### 2.4 选项排版

四个选项（A、B、C、D）之间各空一行。

### 2.5 Markdown 间距

所有块级元素（标题、段落、题干、选项、分隔线、占位符）之间必须空一行。

### 2.6 题干必须「自解释」

错题本会脱离上下文单独展示题干，因此题干里不能出现只能靠版面才能理解的残留：

- ❌ `【题干4】（2）要配制 250 mL…` 单独出现时看不出属于哪一题 → 应把公共条件放进 `【题干4-5】`。
- ❌ 题干里只有 `1.`、`(1)`、`①` 这类题号标签 → 解析器会把它当正文，卡片上只剩一个序号。
- ✅ 需要跨题共享的材料（阅读材料、实验装置、数据表）用 `【题干N-M】` 表达。

### 2.7 缩进与代码块（答题卡片变纯文本的元凶）

Markdown 里**行首 4 个空格或一个制表符就是代码块**。题干标记、选项行、作答占位符一旦被缩进，
页面会把 `<div class="question-slot">` 原样打印出来，答题卡片消失，只剩「第 12 题What is…」和一行标签文本。

| 场景 | ✅ 正确 | ❌ 错误（变成代码块） |
| --- | --- | --- |
| 段落题干下的选项 | `A. 选项内容`（顶格，或最多 3 个空格） | `    A. 选项内容` |
| 段落题干下的作答位 | `【@12】`（顶格） | `    【@12】` |
| 引用块题干 | `> 【题干12】问题？` + `> 【@12】` | `> 【题干12】问题？` + `>     【@12】` |
| 列表题（`21. 问题`）的选项 | 用列表续行缩进（Tab 或 4 空格） | —— |

> 判定口径：`【题干N】` 前面没有列表项时，它与它下面的选项、`【@N】` 都必须是**同一列**；
> 引用块里除了 `> ` 之外不要再加空格。`npm run test:courseware` 会用 marked 实际渲染一遍来验证。

## 三、布局 A：知识点与例题双栏（讲义）

> 适用：知识点讲解与例题穿插，边学边练。

### 核心规则

1. 一个 `#`（一级标题）最多只能有一对 `---`（即最多一个例题区）。
2. 同一大主题下有多段知识点需要分别配例题时，**拆分为多个 `#` 标题**。
3. 每个 `#` 标题下：知识点（左栏）→ `---` → 例题（右栏，题干与 `【@N】` 交替）→（结束）。

### 完整示例

```markdown
# 原电池的工作原理

原电池是将化学能转化为电能的装置。负极发生氧化反应，正极发生还原反应。

---

【题干1】一种锂-空气电池的工作原理如图所示，下列说法不正确的是（ ）

A. 金属锂作电池的负极

B. 电子由金属锂经负载流向石墨烯

C. 石墨烯表面发生的电极反应：$O_2 - 4e^- + 2H_2O = 4OH^-$

D. 每消耗 $1\ \text{mol}\ O_2$，金属锂电极质量减少 $28\ \text{g}$

【@1】

【题干2】铅酸蓄电池工作时，硫酸溶液中的 $H^+$ 向 $PbO_2$ 电极移动。下列说法正确的是（ ）

A. 铅酸蓄电池和氢氧燃料电池都属于二次电池

B. 铅酸蓄电池工作时，$H^+$ 向 $PbO_2$ 电极移动

【@2】

---
```

### 大题（组合题）

公共材料用 `【题干N-M】` 包住，每个小问独立编号、独立作答：

```markdown
【题干9-11】按要求回答下列问题：

【题干9】(1) a 电极的电极反应式为 ______。
【@9】

【题干10】(2) 盐桥中 K+ 移向装置的 ______。
【@10】

【题干11】(3) 电路中转移 0.2 mol 电子时，负极质量变化为 ______。
【@11】
```

## 四、布局 B：题干与作答区分离（纯题目集 / 课后练习）

> 适用：只有题目、统一作答的课后练习与试卷。**化学课后练习、试题详解都使用本布局。**

### 核心规则

1. 一个 `#` 对应一个模块：先罗列该模块全部题干，再用一个 `---` 切到答题区。
2. 答题区只放 `【@N】`，末尾再加一个 `---` 封闭。
3. 答题区**不要**写 `1.`、`4.（1）` 之类的标签；显示顺序由解析器按出现顺序生成，
   卡片角标会自动显示「第 N 题」。

### 完整示例

```markdown
# 模块1 化学计量中的重要物理量

【题干1】下列叙述正确的是（ ）

A. 摩尔是国际单位制中七个基本物理量之一

B. $\mathrm{CuSO_4 \cdotp 5H_2O}$ 的摩尔质量为 $250\ \text{g}$

【题干2】下列叙述正确的个数是（ ）

① 标准状况下，$0.2\ \text{mol}$ 任何物质的体积均为 $4.48\ \text{L}$

② 若 $1\ \text{mol}$ 气体的体积为 $22.4\ \text{L}$，则它一定处于标准状况下

A. $2$ 个 B. $3$ 个 C. $4$ 个 D. $5$ 个

【题干3-4】将一定质量的 $\mathrm{Na_2CO_3}$ 和 $\mathrm{NaHCO_3}$ 混合物加热至质量不再变化。计算：

【题干3】（1）原混合物中 $\mathrm{Na_2CO_3}$ 和 $\mathrm{NaHCO_3}$ 的物质的量之比为 ______。

【题干4】（2）所用盐酸的物质的量浓度为 ______。

---

【@1】

【@2】

【@3】

【@4】

---
```

### 布局 B 的常见错误

| ❌ 错误写法 | 现象 | ✅ 正确写法 |
| --- | --- | --- |
| 题干写成 `1. 化学的学习与研究…`（有序列表） | 抽取到的是答题区的 `1.`，错题本只剩「模块 1 · 第1题」 | 题干前加 `【题干1】` |
| 答题区保留 `4.（1）` 标签 | 标签会被当成题干末尾内容 | 答题区只写 `【@4】` |
| 一题多空共用一句引导语，却把引导语写进第一个空 | 第二个空缺条件 | 引导语用 `【题干3-4】` |
| 小问编号与作答编号错位 | 题干与答案键串号 | 先写 `【题干N】`，再按同一 `N` 写 `【@N】` |

## 五、布局 C：材料型题目（英语阅读 / 完形 / 精读 / 七选五）

英语课件有两种承载方式，**都要求题目本身成为题干**，绝不能把整段原文兜进题干。

### 5.1 精读任务：题干写在引用块里

原文照常排版，题目用引用块紧跟对应段落；**题干标记放在引用块的行首**，作答占位符可以留在引用块内：

```markdown
The shopping excitement was caused by island-wide special customs operations that day.

> 【题干1】找出所有动词，哪些是谓语，哪些是非谓语？如果谓语不止一个动词，哪个动词是语法核心词？
>
> 【@1】
```

- 解析器会去掉 `>` 前缀，题干 = `找出所有动词…`。
- ❌ 写成 `> 1. 找出所有动词…`（没有 `【题干N】`）时，旧课件回退会把**整段英文原文**当成题干；
  一旦原文与题目之间隔着 `---` 或标题，回退失效，题干直接丢失。
- ❌ 只写 `【题干1】` 却把问题放在下一段而没有作答占位符分隔，会把下一段正文吞进题干。

### 5.2 选择题 / 语法填空 / 阅读 / 七选五

| 题型 | 题干怎么给 | 示例 |
| --- | --- | --- |
| 单选（含选项） | 题干标记独占一行，其下是题号 + 问题 + 选项；`【@N】` 紧跟其后 | 见下 |
| 语法填空（空在原文中） | **每个含空的段落**一个公共题干 `【题干N-M】` | `【题干11-13】` + 段落 |
| 完形填空（空在原文中，选项统一列在文末） | 每个含空段落一个公共题干；选项留在原文 | `【题干15-16】` + 段落 |
| 七选五（空在原文中） | 每个含空段落一个题干标记 | `【题干38-39】` + 段落 |
| 书面表达 | 题干标记写在作文要求（含要点）之上 | `【题干44】` + 要求段落 |

```markdown
# 阅读A

【题干21】What are participants in Walk 3 required to do?

A. Get special permits.

B. Bring a survival guide.

C. Join a walking club.

D. Wear proper clothes.

【@21】
```

语法填空按段落给公共题干：

```markdown
## 语法填空 A

【题干11-13】
Previously, water quality in the Li River had suffered greatly from an increasing volume of tourists,
many of [11]______ frequently threw garbage into the river. In order to feed more people, more chemicals
[12]______ (use) to increase crop production. Local officials felt that urgent steps should be taken
[13]______ (restore) the river's original beauty.

【@11】

【@12】

【@13】
```

> 说明：材料型题目的题干是「含空段落」，选项与全文仍在课件正文里，错题本卡片上的
> **「来自《…》第 N 题」** 可直接跳回原文。

### 5.3 英语排版约定

1. 英文题干本身就是题面，不需要再翻译；中文提示（如「找出所有动词」）同样有效。
2. 引用块内的题干不要保留 `1.`、`2.` 的卷面编号——编号由题号角标统一显示，
   重新开始的卷面编号（每段都从 `1.` 开始）会与作答编号不一致。
3. 高亮用 `**…**`，解析器会在题干里自动去掉加粗标记。
4. 选项行可用制表符缩进；题干片段会保留缩进后的 `A./B./C./D.`。
5. 题干里出现 `$…$` 之外的美元符号时请用 `\$` 转义，避免公式渲染错位。

## 六、旧课件的兼容与迁移

解析器保留一层兼容（`source: 'nearby'`）：如果一道题没有 `【题干N】`，会从作答占位符向上找
最近的「题目起始行」（`> 1. …`、`1. …`、`- 单词`），把它到占位符之间的内容当作题干。
该回退在任何一次排版调整后都可能失效，因此：

- 校验工具把 `nearby` 记为**警告**；`--strict` 下记为错误。
- 校验工具把 `fallback`（题干丢失）记为**错误**，CI 会失败。
- 迁移旧课件时优先补 `【题干N】`，不要依赖回退。

## 七、校验工具

```powershell
npm run test:courseware                     # 错误即失败（CI 使用这条）
node tutor-nest-vue/scripts/check-courseware.mjs --verbose   # 打印每道题解析出的题干
node tutor-nest-vue/scripts/check-courseware.mjs --strict    # 旧课件回退也算错误
```

检查项：

| 检查 | 级别 |
| --- | --- |
| 有作答占位符的课件，每道题都能解析出题干（不是 `fallback`） | 错误 |
| 题干非空且长度 ≥ 5 字 | 错误 |
| `【@N】` 编号唯一 | 错误 |
| 题干标记覆盖的题号都有对应作答占位符 | 警告 |
| 依赖旧课件回退（`nearby`） | 警告（`--strict` 为错误） |
| 编号缺号（历史课件） | 警告 |
| `【@N】` 与 `【@】` 混用 | 警告 |
| 作答占位符被缩进成代码块、渲染不出答题卡片 | 错误 |
